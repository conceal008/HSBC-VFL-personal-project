# 本地功能训练工程验收

> 编写日期：2026-10-01 ｜ 版本：v1.0 ｜ 状态：两数据集最终 DF 功能训练及私有验收完成
> 数据来源：S5.P2 运行副本、各方访问/认证/输出日志、合成冒烟与本机质量回归
> 口径基准：DR-M5-001；本地功能模拟、可信宿主管理员、半诚实且不串通的参与方

本步骤将本轮双物理主机条件改为两个无共享挂载的 Linux 虚拟机。双方拥有独立非特权账户、目录、磁盘与证书私钥；隐语原生联邦通道和 SPU 通道均启用双向认证。该变更没有解除正式客户 PSI、真实业务数据或生产安全的门禁。

| 验收内容 | 实现与证据 |
|---|---|
| 本方读取与输入冻结 | `prepare_local` 读取本方只读投递，核对输入哈希；训练结束再次核对。私有证据为各方 `logs/isolation.json`、`logs/output_boundary.json`。 |
| 权限负例 | 非 root、无 sudo、无宿主共享挂载；读取真实存在的禁止目录文件返回权限拒绝；对方 SSH 服务由管理端先证实存在，再由训练账户证实连接被拒绝。 |
| 通信身份 | 无客户端证书的原生联邦/SPU 连接均实际拒绝；数据任务须在这些检查通过后启动。证据为各方 `logs/tls_checks.json`。 |
| 安全计算 | CHEETAH 两方秘密分享执行组聚合、设计矩阵、优化与预测；明文残差和联合权重不释放，权重份额仅在本方虚拟机保留。 |
| 输出接收方 | 预测与评价仅给 Alice；Bob 检查无标签/处理组、无预测文件和评价报告。联邦驱动只接收状态与预先允许的工程元数据。 |
| 实验追溯 | 每个模型/seed/候选单独 `trainings/` 目录，保存代码、环境、配置、本方处理文件引用与哈希、结果、过程日志。失败亦新建并保留。 |
| 统计流程 | 同一冻结切分，五个初始化/批次顺序种子；先 L1 后 L3；验证集选参；测试指标及配对差值由 Alice 输出自助法区间。 |

公开数据的指标、预测、处理参数及带输出 Notebook 只在仓库外私有目录。训练后由可信管理员将各方获授权产物导出至对应目录；这不是联邦驱动在训练过程中获得预测。模型份额和本方变换后的数据行均不汇集到宿主。

## 模型调整与失败记录

联合模型使用固定学习率候选、L2 正则、输入裁剪和固定优化轮数；Hillstrom 使用处理组与特征交互的线性 S-learner。Alice 单方参照同时搜索逻辑回归与梯度提升树，不能只用弱单方模型制造联邦增量。L1 组均值仅在安全计算内使用，不能冒充原低成本明文聚合路线。

逐行秘密索引的实际规模尝试开销过大，中断后完整保留已完成日志。改成数学等价的秘密 one-hot 矩阵连接后，单块 FM128 的尝试又触发虚拟机内存不足，未作为成功实验接纳。最终采用分块聚合、训练与预测，复用同一 seed 的安全设计块；末批零填充，所有真实训练行均参与。

FM64 是计算的算术环位宽，不是证书或协议密钥强度。旧分块 T3 方案在合成冒烟中与 FM128 参照比较：相同 seed 11、相同两轮训练，最大预测差约 0.00025，小于配置容限 0.001。来源为本机 `8-9月/功能模拟环境/precision_check_v1.json`，其中记录两个独立冒烟目录与各路线/切片差异；具体配置与代码指纹在各目录 `code/runtime.json`。此检查只说明该合成条件下的数值接近，不证明所有真实输入范围都不会发生溢出或数值误差。

## 解释与安全边界

UCI 最终 DF 双方完整训练、Notebook 和私有文件验收已通过；Hillstrom 最终 DF 双方训练、Notebook 和私有验收亦通过。模型效果仅在私有分析中解释，工程通过不能替代增益确认。

五个模型种子共用同一测试切片，不能称为五个人群复现；自助法区间是该冻结切片下的条件区间。未执行多个独立切分、p 值或多重比较校正，不能仅凭点估计使用“显著”一词。UCI 按原始顺序冻结的切片不能冒充严格日期外推实验；Hillstrom 的两组邮件分别与未发邮件组比较，策略价值是试验数据的名单回测口径，不能外推银行收益。

安全模型的固定轮数、运行副本声明的 sigmoid 近似及线性容量与单方精确逻辑回归/树模型不同，效果差异同时包含特征与优化器/容量的影响。近似模型分数未做概率校准。后续若要识别纯特征增量，需增加同优化器的安全 active-only 消融并先声明新的实验，不能看本轮测试结果后回头选参。

本轮输出诊断为假设攻击者取得分数和真实标签后的损失型成员推断。实际分数只给 Alice，该诊断不能证明不存在属性推断、特征反演或模型反演；UCI 训练/测试分布变化也可能使成员诊断偏离随机水平。允许给 Alice 的候选预测和训练集分数有残余统计泄漏面，不能对外宣称绝对零泄漏。进入更强安全目标前，应限制输出和查询次数，评估聚合释放或差分隐私及对应效果损失，并针对恶意参与方和宿主管理员另行设计防护。

宿主管理员能接触两个虚拟机，云上同一管理员账户也有相同边界；若该管理员不可信，需要独立管理域、适当的机密计算/证明或真实双主机安排。本轮没有完成这一威胁模型，也没有运行真实客户 PSI。

## 连续近似修正轮（执行前冻结）

旧 T3 轮已完成实际训练；UCI 来源轮由于投递清单误列未使用文件而在收尾失败，在新恢复目录核对三份实际输入、处理数组、完整候选、代码及预测复制一致性后收尾。来源 failed 状态不修改。Hillstrom 旧轮正常完成。两轮及其日志永久保留，但不作为本次连续近似方案的模型验收。

核对锁定版隐语 `utils/sigmoid.py` 后确认：T3 在区间外已有硬截断，不能把硬端点现象说成未截断、溢出或协议泄漏。新方案改用隐语原生连续有界 SR 近似，并在每个安全训练块之后于 MPC 内投影权重至 [-10,10]。特征裁剪、数据切分、候选学习率、轮数和评估定义保持原预声明配置。预测不再先裁剪掩盖异常：MPC 检查原输出位于 [0,1]，Alice 在落盘前检查有限性，双方只接收有效性布尔，分数仍仅给 Alice。Alice 用训练分数检查端点比例不超过预声明 1%；失败即整轮失败，不用验证/测试挑选该阈值。

两数据集重新建独立轮次，从头训练。新增 SR 合成数值参照、真实双 VM 冒烟及 FM64/FM128 对照后才启动数据训练。旧 T3 的位宽对照不能替代 SR 对照。工程限值用于拒绝不合格运行，不证明概率校准或全范围安全。UCI 旧测试结果已被查看，新轮属于工程/方法复核；正式确认仍需要新的未查看人群或时间切片。Hillstrom 旧测试指标尚未用于此次修正。修正根据训练分数饱和与已安装近似实现决定，不能根据新测试表现继续调参。

额外日志审查发现早期 T3/合成尝试显式开启了 SPU 协议 trace，可能保留份额/中间值。既有私有日志仅可信宿主可见、两方训练账户仍无法跨读，但不满足最小日志原则，不能当作“宿主未汇集协议内容”的证据。旧目录保留受限访问、禁止共享。新修正轮关闭 trace 路径并将 trace 内容长度置零，验收强制检查无协议 trace 导出；只导出工程状态日志。该发现及处理均写实验日志。

新 SR 双 VM 合成冒烟的 FM64/FM128 最大预测差约 0.00044，低于冻结容限 0.001；相同训练代码与配置（除算术位宽），相同 seed11、两轮、所有三切片。证据为本机 `8-9月/功能模拟环境/precision_check_v2_sr.json` 和独立 provenance 核验文件。两轮均无协议 trace 导出。此对照不覆盖所有数据条件，也不等同真实业务安全证明。

## DF 修正轮（取代 SR 的实际模型验收）

SR 正式 UCI 在完整 L1 及部分 L3 后触发原分数范围检查，整轮 failed，未启动 Hillstrom，未取得完整新测试评价。纯合成 logit 网格在相同 SPU/CHEETAH/FM64 上复现 SR 小幅越界和大输入失真；理论连续有界不能替代实际定点实现验收。不能将此问题仅说成舍入，也不能在未检查内部实现前断言具体溢出位置。

相同秘密输入网格下，隐语原生 DF `0.5*x/(1+abs(x))+0.5` 保持有界和单调，没有平方/平方根路径。最终方案将 sigmoid 改为 DF；保持严格原概率 [0,1]、Alice 有限性和训练端点≤1%要求，没有事后放宽数值或隐私判据。输入裁剪、权重界限、学习率候选、轮数、五 seed 与全部评估定义不变，另建目录从头训练。模型近似变化依据纯合成数值和工程失败，不依新测试表现。先重新核验 DF 广域网格、FM64/FM128 及两任务冒烟，再运行真实数据。

SR/T3 章节保留为尝试历史，不再作为最终模型方法。DF 分数也未校准，工业与独立验证边界维持。
