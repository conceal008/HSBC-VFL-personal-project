# 完整联合数学核验的运行与解释

> 编写日期：2026-10-05 ｜ 版本：v1.0 ｜ 状态：执行协议
> 数据来源：configs/joint_numerical.yaml、components/joint_diagnostic.py 与 joint_vm.py
> 口径基准：仓库规范、DR-M5-001、S5.D1、用户授权开始实验

本步骤是候选对照设计 G00 的前置实验，限定纯合成数据，不属于 C01 方法增益实验。两个任务形式分别覆盖普通响应预测和两处理组潜在响应预测，名称对应既有接口，不表示使用了真实 UCI 或 Hillstrom 数据。

冻结参数见 `configs/joint_numerical.yaml`：公开生成 seed、五初始化 seed 和分别命名的五批次顺序 seed；训练/验证/留置合成数据互不重叠。合成留置数据只登记输入哈希，不读入训练/评估。训练数据采用整批加仅一个真实记录的尾批，尾批零填充包含零偏置，以覆盖填充与分块行为。各方只拟合自己的训练标准化器，裁剪后加入秘密计算；标准化参数与矩阵留各自 VM。

完整联合设计在 MPC 中完成，顺序为 Alice 字段、Bob 字段、处理组指示、按字段优先排列的两处理组交互、偏置。原生 SS-SGD 采用 DF 近似、L2、固定分母、每块投影；不得把它与使用精确 logistic 链接函数或不同正则缩放的 sklearn 模型称为同算法参照。

Alice 的数值参考只从公开纯合成生成参数再生成数组，不读取 Bob 目录。独立 NumPy 设计和梯度方程与原生更新字节码相互对照；数据重建只在 `is_smoke`、`synthetic_only` 三处标记同时为真时允许。参照重建能力不能用于实际数据。固定阈值见步骤声明；所有训练/验证的 factual 或 potential 预测逐项核验，任一不通过阻断后续方法对照。五 seed 的误差均值区间仅描述计算误差变化，不能解释为业务增益区间。

运行入口：

```bash
python modules/m5_modeling/components/joint_vm.py --workspace <本机私有工作区> --dataset uci_bank_marketing
python modules/m5_modeling/components/joint_vm.py --workspace <本机私有工作区> --dataset hillstrom_email_marketing
```

两次运行顺序执行，禁止同时占用同一组认证通信端口。依赖已部署的两个 Lima VM 与 Linux 固定环境。宿主只投递配置/纯合成输入和收回许可产物；Notebook 在各自无 sudo 的账户内执行。Notebook 入口 `notebooks/S5.V1_joint_numerical.ipynb` 要先由调度器提供新轮次的 `RUNTIME_PATH`，不能直接在宿主导入双方数据。旧轮次不会覆盖，失败或中断另起新目录。

每次拟合 `trainings/<名称>/` 含 `code/ data/ results/ logs/`，代码和配置、环境锁、输入与清洗数据引用、进度和检查结果分开留存。清洗矩阵与模型份额留 VM；授权收回包排除它们及权重和协议 trace。Bob 不接收概率、标签、残差或联合明文权重。实验索引统一维护，负结果和预检失败保留。

公开交付只包含生成器、配置、代码、纯合成数值检查汇总与已执行 Notebook 的汇总输出，不提交合成样本或凭证。权限、认证和数值通过仅证明规定的功能模拟与数值判据；真实 PSI、独立业务人群、全部攻击验证、恶意宿主和生产安全仍未完成。前置通过之后，C01 仍需单独冻结协议、声明和提交，只用原 train/validation 开发；旧 test 不再用于选方法。
