## 结果

A_secure（隐语 SS-XGB，训练全程秘密分享，配置与 A 相同）按均值训满 150 棵约需 6.35 小时，超过预注册单次拟合上限 6 小时。按 DR-M5-010 · D-3 训到 141 棵（拟合墙钟 5.97 小时）停止，**记为超出上限、未完成**；预注册的 A_secure − A 不报告，下表均为**描述性**比较。

| 比较（开发评估集 20,351 位客户、586 个正例） | AUROC 差 [95% 区间] |
|---|---|
| A_secure（141 棵）− L4_T（明文集中式，141 棵） | −0.001 [−0.004, 0.002] |
| A_secure（141 棵）− A（隐语 SGB，150 棵） | +0.000 [−0.002, 0.003] |
| A_secure（141 棵）− L1_k10 | +0.043 [0.033, 0.054] |

| 成本（同一台 2 核机器） | A（SGB） | A_secure（SS-XGB） |
|---|---|---|
| 运行方式 | 单进程模拟，无网络 | 两进程生产模式，本机回环 |
| 每棵树耗时 | 约 22 秒 | 约 152 秒（约 6.9 倍） |
| 150 棵耗时 | 0.92 小时 | 约 6.35 小时（外推） |
| 每棵树两方合计通信 | 未测（单进程） | 约 32 GiB |
| 每个进程峰值内存 | 未测 | 约 3.3 GB |

## 适用边界

- 拟合墙钟 = 首段全局准备 + 每棵树训练耗时；分段续训的进程启动、重做准备与回放（880 秒）单列，不计入（DR-M5-010 · D-3）。
- 两臂运行方式不同，耗时比只作同机相对量级，不作部署耗时估算；通信量按本机回环发送字节计（两方合计，含控制消息）。
- SS-XGB 两次训练结果不完全相同（定点运算舍入使接近并列的分裂翻转，DR-M5-010 · D-4）；只拟合一次，区间未含这部分波动。
- 续训在小样本上与不间断训练核对过（根节点逐棵相同，预测差异与两次不间断训练同量级，见 S5.G2-1）。
- 开发评估集正例 586，低于预注册目标 700（同 S5.G1）；可检出差异约 0.006（同棵数比较）至 0.024（相对 L1）。
- 本步只测精度与成本；SS-XGB 训练中分裂由哪方持有、持有方的分裂阈值仍可见，这部分披露未评估。
- 逐行打分、检查点（权重份额、分裂信息）、客户号与日志只在会话临时目录或维护者本机私有目录，不入仓库。
