- ⚠️ **L1 的合规成本不得按「低一个数量级」估计**（M0 的 S0.4 定性，CBA-006）：
  k-匿名聚合统计满足 PIPL 第 73 条第（三）项的去标识化，但**不当然满足**第（四）项的匿名化
  （匿名化要求「不能复原」，而 k-匿名对属性推断与多源组合攻击的防护有限）。
  在给出匿名化的量化论证前，它按个人信息处理——L1 与 L3 的合规成本差距要比原假设小得多，
  「VFL 是否划算」的答案可能因此改变。比较 L1 与 L3 时必须把这条计入。

- ⚠️ **L3 须增设一条「单向流动」分支**（M0 的 S0.5 发现）：CBA-005 梯度（cn→hk）已按敏感个人信息
  定性，而 1 万人以上敏感个人信息必须走数据出境安全评估（《促进和规范数据跨境流动规定》第七条）。
  任何达到可验证规模的双向 L3 方案都必然落入最重的出境路径。
  **若把 L3 改造成只有 hk→cn 的单向流动（被动方送嵌入、主动方不回传梯度），
  cn→hk 方向不再提供个人信息，出境路径可大幅减负。** 这条须作为 L3 的独立路线评估，
  而不是等到 M8 才发现合规成本不可承受。

- ⚠️ **M5 需回答一个决定合规路径的实验问题**（M0 的 S0.6 结论）：
  形态 B（单向流动，被动方送嵌入、主动方不回传梯度）在合规上从**安全评估直接跳到豁免**，
  优势压倒性。代价在建模侧——不回传梯度则被动方编码器无法随标签迭代优化。
  **表示质量会下降多少，只能由 M5 用实验回答**。判据：若下降幅度小于 L3 相对 L1 的增益，
  形态 B 是全局更优解；若下降到与 L1 无异，则 VFL 在本场景的价值须重新评估。
  M0 的 S0.9 判决在等这个证据。

**放行判据核对**：

- 基线 5/5 级 ✅（L0/L1/L2/L3/L4，其中 L3 有 3 条路线共 5 个变体）
- **L1 完成时点严格早于任何 L3 实验** ✅（L1 组件先于 L3 组件实现；
  后续对 L1 的调整全部为**加强**方向：分段扫描、k 扫描、安慰剂对照、40 种子）
- 种子 ≥5 且全阶梯一致 ✅（主网格 5 种子；关键对照 40 种子）
- 场景覆盖 ≥6 ✅（8 个场景）

**实现正确性（等价性检验）**：L3a 联邦 LR 0.7978 ≈ L4 集中式 LR 0.8003；
L3b 纵向 GBDT 与 L4 集中式 GBDT 完全相等（0.7697）。协议无损，符合数学预期。

**核心结论**：L1 只捕获纵向联邦价值的一小部分。三个独立口径互相印证：

| 口径 | L1 捕获比例 |
|---|---|
| 40 种子安慰剂对照（固定超参） | 12.3% |
| S5.4 正规选参（验证集，3 场景 × 5 种子） | **2.1%** |
| S5.4 oracle 上界（测试集选参，等于作弊） | **15.5%** |

**调参救不回 L1。** 其瓶颈是结构性的——分段键只能用主动方特征，
回传统计量因而是主动方特征的函数。

## S5.4 补充（2026-09-03）：超参搜索与 C1 稳健性

| 产出 | 位置 |
|---|---|
| 搜索组件 | `components/search.py` |
| 网格配置 | `configs/hyperparam_search.yaml` |
| 正规选参结果 | `results/hyperparam_search.csv`（105 行） |
| oracle 上界 | `results/oracle_upper_bound.csv` |

**方法要点**：60/20/20 三分，**选参只看验证集**。在测试集上选参会让搜索空间大的
级别虚高更多，而本文刻意给 L1 最大网格（60 组 = L0 的 12 倍），污染方向恰好
**有利于 L1**——那同样会毁掉结论。该不变量由 `test_选参只看验证集` 锁定。

**方法自检**：「验证减测试」的乐观量随网格增大而增大
（L3b 81 组 0.0412 > L3c 54 组 0.0241 > L3a 27 组 0.0114），说明选参乐观度被正确检出。

**次级发现（须知其来源）**：调参后 L3a 联邦 LR（0.8352）与 L3c SplitNN（0.8210）
差距缩小，而 L3b 纵向 GBDT（0.7954）始终落后。本 SCM 的信号是潜变量的**线性组合**，
对线性模型有利——这是**生成假设带来的偏向，不可外推到真实数据**。
