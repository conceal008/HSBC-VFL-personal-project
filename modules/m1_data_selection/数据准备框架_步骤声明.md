# Notebook 数据准备框架：步骤声明

> 编写日期：2026-09-27 ｜ 版本：v1.0 ｜ 状态：执行前声明
> 数据来源：用户要求、M1 README 与维护约束第 9.1 节
> 口径基准：共同客户联合营销；公开数据仅作研究代理

步骤：S1.P1（用户要求新增的数据准备前置步骤，不代替原 S1.1–S1.9 的验收）。

- will_produce：Notebook 入口、可复用处理组件、UCI/Hillstrom 配置、训练集拟合的各方预处理、冻结切分、新数据与独立结果目录、原件哈希保护、运行快照、测试、带输出的本地 Notebook、运行准则。
- will_not_produce：修改任何原始数据、模型效果结论、真实 PSI、联邦训练、跨主机安全部署、其余数据集全部适配、M1 完整验收。
- success_criteria：两份 Notebook 从头运行成功；原件哈希前后一致；输出目录分离且不能覆盖；训练/验证/测试记录互斥；Bob 无标签；矩阵数值有限；配置重跑数据逐字节一致；关键防污染和防泄漏条件有测试。
- risk：UCI 缺稳定客户 ID，记录级划分无法保证客户级互斥；语义切分仍为构造条件；Hillstrom 为邮件试验而非银行；所有数据派生输出仅存仓库外。

下一步：回到 S1.1 定义候选评估矩阵，补齐正式选型与四种切分协议；本步骤不提前放行这些要求。
