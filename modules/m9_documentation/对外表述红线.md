## 二、可以说，但必须带限定

| # | 可以说 | 必带的限定 |
|---|---|---|
| Y1 | 纵向联邦相对低合规成本替代方案有真实增量 | 「在合成数据的机制层面上」；且须给出 L1 的对照口径 |
| Y2 | L1 只捕获价值的一小部分 | 给出三个口径（2.1% / 15.5% / 12.3%）及其定义差异，不要只报一个数 |
| Y3 | 上行加噪是有效的特征保护 | 「对特征推断有效；对标签推断无效」——两者不可混为一谈 |
| Y4 | 价值取决于互补性 | 加一句「还取决于互补性以什么形式起作用」（C9：可实现比例相差近四倍） |
| Y5 | 实体对齐不是主要风险 | 「在本合成数据的匹配噪声范围内」；且错配在合规上本身即是事故 |

## 三、必须主动说的

对外材料若涉及本项目结论，**以下三句应主动写明**，不能等人问：

1. **全部结论来自合成数据**，只验证机制，不承诺真实业务效果。
2. **本项目不设合规角色**，涉法判断未经法务复核。
3. **无防护的协议是双向完全泄露的**——这不是理论风险，是本项目实测到的。

第 3 条尤其不能省。它是本项目最有价值的发现之一，
**隐去它去讲「联邦学习保护隐私」，是把风险留给下一个人。**
