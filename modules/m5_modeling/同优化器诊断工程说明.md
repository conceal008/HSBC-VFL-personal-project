# 同优化器诊断工程说明

> 编写日期：2026-10-03 ｜ 版本：v1.0 ｜ 状态：方法说明，实际验收见本步骤交接记录
> 数据来源：`components/active_diagnostic.py`、`components/active_vm.py`、`configs/active_diagnostic.yaml`；运行记录位于本机私有实验目录
> 口径基准：DR-M5-001；可信宿主、半诚实不串通的本地功能模拟

本步骤在 S5.P2 已查看的冻结切片上增加主动方安全参照，解释优化器与字段变化的混杂。它不构成新的独立人群验证。执行前声明保存在 `S5.P3_同优化器诊断_步骤声明.md`，不随实际效果重写。

## 模块与信息边界

| 模块 | 功能 | 可见信息 |
|---|---|---|
| `active_vm.stage` | 核验旧轮通过状态、核心代码及冻结配置，建立新目录并部署只读代码与输入 | 可信环境提供方负责装载；各方业务账户只能读自己的输入 |
| `prepare_active` | Alice 使用训练集拟合处理参数，校验与上一轮 Alice 处理矩阵一致；Bob 只读记录键 | Alice 自有字段、标签和处理组；Bob 自有记录键及公开维度 |
| `fit_reference` | Alice 本地执行与安全模型相同的原生批更新数学式 | 仅 Alice 字段；完整明文权重保留 Alice 虚拟机 |
| `train_active` | 原生 CHEETAH 秘密计算；Bob 不提供特征值 | 秘密份额、固定协议日程和有效性布尔；明文预测仅给 Alice |
| `freeze_selection` / `unlock_test` | 所有验证候选完成后冻结选择，之后解锁测试解析 | 选择索引仅 Alice；Bob 不获取索引；训练输入引用不含测试矩阵 |
| `finish_seed` | 核验旧预测指纹，复用冻结比较路线，生成配对区间 | 获授权的 Alice 私有预测和标签 |
| `verify_diagnostic` | 独立核验目录、权限、代码与配置指纹、输出接收方、Notebook 和区间 | 工程证据；本机私有结果由可信维护者核验 |

各方采用独立非特权账户、独立 Linux 虚拟机、目录权限和双方认证通道。可信宿主管理员仍有访问能力；这项假设必须保留。明文逐条预测属于允许给 Alice 的输出，仍可能构成推断攻击面，不能把权限验收解释为绝对零泄漏。

## 冻结优化器与本地参考

实际数据参数逐项与原轮一致：五个初始化/批次种子、两个学习率、十二轮、固定批次与分块、DF 近似、L2、权重投影、训练端点限制。主动方初始化从原联合设计坐标映射，处理组及主动方交互坐标一起保留，Bob 坐标不进入主动方设计。选择仅看验证；不翻转测试分数、不据测试结果调参。

锁定版本的原生更新包含 SPU 缓存提示，直接在普通 CPU 执行会报未注册 custom call。仅移除提示后，开发探针仍发生退出码 255，完整原因尚未确定。因此本地参考保留原生更新函数的字节码，复制其全局绑定并改用 NumPy 张量、同一 DF 数学表达式，缓存提示使用恒等映射。它是**同数学式的 CPU 参考**，不是“原生 JAX 执行环境完全不变”。原生函数文件指纹和适配说明保存在每次参考训练的日志；不修改全局 SPU/JAX 或安全训练的更新函数。

安全路径继续使用锁定版原生更新和 SPU。训练、验证和所选测试预测分别与本地参考比对，预先固定最大绝对误差阈值。超阈值如实标记数值不等价，不能再把对照差异解释为纯字段效应；概率无效或端点限制失败则停止该轮。主动方数值一致也不证明全字段联合设计正确，后者需另一步验证。

## 实验目录与复核

私有轮目录位于本机 `8-9月/同优化器诊断/<数据集>/<新轮ID>/`；每个模型有独立 `code/ data/ results/ logs/`。每数据集运行十个安全候选和十个 Alice 本地参考，Bob 的十个目录是安全协议参与记录，不另计模型。原始数据、历史结果和旧预测只读，新处理矩阵写入各自虚拟机新目录。

导出到可信维护者私有目录时排除处理矩阵、模型份额、完整权重及协议 trace；Alice 的派生预测和带输出 Notebook 留在私有目录。Public 仅提交代码、配置、工程记录与清空输出的 Notebook。

纯合成冒烟的模型日程缩小，Hillstrom 排序比例单独使用配置中的冒烟比例，避免小测试集随机重采样出现空处理臂。这项差异明确属于工程冒烟，不能冒充实际数据验收；实际数据沿用原排序比例与重采样次数。失败轮及验收拒绝记录永久保留，不覆盖成通过状态。

置信区间来自同一冻结人群内的重采样；五个训练种子不等于五个独立人群。Hillstrom 的实验内增量排序不等于银行真实新增收益。真实客户 PSI、恶意参与方、恶意宿主及完整输出泄漏评估仍未完成。

## 运行入口

```bash
python modules/m5_modeling/components/active_vm.py --workspace /绝对路径/汇丰/8-9月 --origin-round /绝对路径/上一轮通过目录
```

部署后各方运行 `notebooks/S5.P3_active_diagnostic.ipynb` 的独立副本。纯合成冒烟额外指定 `--smoke`。先核验环境锁与权限，通过冒烟后再运行实际数据；不要拿失败轮当成功轮复用或放宽验收条件。
