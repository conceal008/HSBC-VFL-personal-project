# UCI/Hillstrom 外部数据 L0 执行说明

> 编写日期：2026-09-30 ｜ 版本：v1.0 ｜ 状态：S5.P1 本机验证
> 数据来源：S1.P2 隔离准备的两组公开数据输入；具体实验 ID 与哈希留在本机私有日志
> 口径基准：共同客户联合营销；仅 Alice-only L0 工程前置

从 `modules/m5_modeling/notebooks/S5.P1_external_l0.ipynb` 编排运行。配置在 `configs/external_l0.yaml`，核心逻辑在 `components/external_l0.py`；`components/launch_external_l0.py` 把 Notebook 和代码复制到新实验目录，再以 macOS 默认拒绝沙箱运行。仅允许读 Alice 已冻结的数据、代码快照和 Python 环境；指标、选参结果、带输出 Notebook 与结果分析留在 Alice 私有运行目录。控制端只记录状态与私有地址，仓库 Notebook 的数据派生输出清空。

执行顺序是输入哈希和双方访问边界检查、训练切片拟合缩放器、验证切片选超参、固定测试切片评估。模型种子、bootstrap 种子与已有切分种子分开记录。UCI 报响应预测诊断；Hillstrom 将两个随机邮件组各自与未发邮件组比较，不把两种邮件合并。置信区间只反映同一测试切片的重采样，不代表跨时期或跨机构泛化。

本步骤没有读取 Bob 特征，没有 PSI、跨方通信、安全联合训练或模型泄漏验收。结果不得用于声称联邦相对单方的增益，也不得外推到银行理财产品。后续 P4 必须先确认交集披露范围、接收方、双方身份认证和真实协议的输出边界；P6 才能在同一冻结切分上执行 L1 与安全 L3。

本机重跑的私有验收见 `8-9月/实验日志/` 中后缀为 `_l0_` 的新增实验；新运行只追加新目录，不覆盖 S1.P2 或既有模型结果。未经两台独立主机、密钥与网络边界验证，不标记为物理隔离通过。
