# S7.P2 新增实际输出重评

> 编写日期：2026-10-11 ｜ 版本：v1.0 ｜ 状态：联合诊断完成且同步main后执行
> 数据来源：S5.E4全八新联合/十固定融合及S5.E5四格48轮授权预测；原完整开发分区
> 口径基准：用户本轮先诊断再输出重评授权；通过线11及既有M7复评

will_produce:
- 两任务22新增输出组全部五seed，三固定视图exact/rounded/binary；660输出压力场景。复用原攻击种子、量化位数、阈值、辅助/评估分离和标签/处理匹配。
- 20包含Bob信息的输出组密态辅助属性oracle探针（每组每seed基线及三视图，共800拟合）；被动真值不离开Bob，Alice只获原授权汇总误差。四主动方48轮输出只作本地输出压力参照。
- 输出代理窃取的误差及排序重合、成员攻击与feature-only基线/增量、三视图可用性（预测/增量指标）、常量退化识别和五seed配对区间。
- 两来源每方矩阵逐项相等、源码/配置/源预测hash核验；test不投递，Bob无新分数能力。逐攻击独立目录、私有执行Notebook和结果，main与系统日志同步。
will_not_produce:
- 不训练/选择新的业务模型，不删除不利输出视图，不声称辅助oracle是现有Bob攻击能力。
- 不把成员攻击绝对AUC直接解释为训练记忆；只把匹配feature-only增量作为同源条件证据。
- 不将binary常量造成的低误差/高重合称安全或窃取成功，不将本轮攻击未命中称零泄漏/生产准入。
- 不使用封存确认集，不新增Bob预测、梯度、权重、属性真值的接收权限。
success_criteria:
- 全组/视图/五seed及正负控制、MPC数值控制、两源矩阵/行对齐、隔离/认证/输出限制全部通过，所有风险和退化保留。
- CI只解释条件于同源数据与攻击/模型seed；新模型效能和攻击风险分别呈现，不混作增益证明。
risk:
- 辅助oracle范围只覆盖一项预先指定属性，不是全属性攻击下界的完备证明；恶意/合谋与长期查询累积仍不放行。
- 训练增加可能改变记忆/属性信号，概率量化不等于差分隐私；固定梯度阈值布尔也属于受控披露，需要在日志中列出。
