# S5.P2 本地安全功能训练步骤声明

> 编写日期：2026-10-01 ｜ 版本：v1.0 ｜ 状态：执行前声明
> 数据来源：用户本轮指令、S1.P2 冻结两方输入、S5.P1 单方参照、锁定版 SecretFlow v1.14.0b0
> 口径基准：共同客户联合营销；本轮为公开代理数据的功能模拟，宿主管理员为可信环境提供方

will_produce:
- 本地功能模拟实验要求与决策记录；取代本轮双物理主机验收条件，保留双方数据访问、协议与输出约束。
- 两个 Linux 虚拟机、各方独立账户/目录/权限，冻结输入只读，安全计算后端仅接受各方秘密份额；验证越权访问及通信身份。
- 在同一冻结切分上建立单方强参照、仅在安全计算内使用聚合特征的 L1 对照和联合逻辑回归；先 L1 后 L3，验证集选参、至少五个训练种子和置信区间。
- 每次训练创建独立目录保存代码/配置/Notebook/环境快照，data/、results/、logs/ 分离；私有输出不进入公开仓库，失败亦留档。
- 以 Alice 为唯一预测与评估接收者；Bob 不接收标签、残差、逐条预测或明文参数；模型输出攻击评估与暴露范围实测如实记录。

will_not_produce:
- 不宣称绝对零泄漏、对抗恶意宿主管理员、物理隔离或生产安全；安全结论限定于已声明的半诚实参与方和已测访问/输出路径。
- 不披露双方原始特征、跨方明文标识或秘密分享份额汇总；不以普通明文训练冒充联邦训练。
- 不把预对齐冻结切片的安全一致性检验称为真实客户 PSI；本轮无需重新披露 PSI 交集，真实业务 S0.9 未被本轮裁定。
- 不在测试集选参、覆盖原件/旧结果或把零售/响应代理结果外推到银行业务。

success_criteria:
- 明确并实测两方账户/虚拟机/目录边界；本方只读取已验收输入，哈希前后不变；任何隔离或协议检查失败则停止数据训练。
- 安全联合计算真实运行，标签与参数不在 Bob 或控制端明文出现；训练过程、输出授权和泄漏测试均有本轮记录。
- 两组数据至少五种子、有区间、同冻结切分；UCI 预测指标与 Hillstrom 两邮件组的增量排序/策略价值口径分别处理。
- 有可运行 .ipynb 及独立训练目录，源代码与结果可追溯；完整仓库门禁通过后提交推送。

risk:
- 本机内存和 Linux 原生依赖可能限制虚拟机资源；不得悄悄改成共享明文进程后宣称满足本步骤。
- MPC 保护计算过程，但允许给 Alice 的预测仍可能包含成员信息；必须保留输出攻击测试与剩余风险，不把实验测试当数学安全证明。
