## 目标

把业务诉求翻译为可证伪的预测命题，输出跨境对象分级清单与可用样本域定义。这是整个方案的地基。

## 上游输入

无（本模块是起点）

## 输出契约（本模块必须产出）

`problem_statement.md` · `registry/cross_border_assets.yaml` · `compliance_to_technical.csv` · `route_comparison.md` · `DR-M0-*.yaml`

## 量化放行判据（不达标不放行）

- 预测命题 1 句、四要素齐全、可证伪
- 跨境对象覆盖 8/8 类，每类 ≥1 条法条引用
- 独立推演路线 ≥3 条，每路线 ≥5 个监管质询且回答率 100%
- 主线+回退线各 1 条，回退触发条件可量化
- 约束映射覆盖率 100%；法务独立复核追问 0 次

## 当前结论

暂无。本模块尚未开始，`step_ledger.yaml` 中 `steps` 为空。

## 未决问题

- 预测命题四要素（人群 / 时点 T / 窗口 Δ / 转化定义）需求方尚未确认
- 产品 P 的类别未定，直接决定特征敏感度与同意口径
- 业务最小可行规模（一个数字）未定，M3 折损漏斗的判负线依赖它
- PSI 交集是否明文落地未定（五个必须先定的决策点之一）
- 标签方是内地还是香港未定，决定 VFL 架构与主要威胁面
