# C01 完整分区训练运行说明

> 编写日期：2026-10-06 ｜ 版本：v1.0 ｜ 状态：冻结执行协议
> 数据来源：`configs/nonlinear_full.yaml`与S5.E2声明；S1.P2冻结train/validation
> 口径基准：用户完整数据训练要求、DR-M5-001、仓库规范

本步骤把C01四格训练由固定预试验扩到全部冻结train，并在全部冻结validation上评价。配置max_rows的train/validation均为null；持有方断言输入与使用记录数完全一致。记录仅按公开salt+本方key重排序，没有抽样上限。原切分seed=20260927，记录排序salt=20261005，五初始化seed=11/22/33/44/55，批次顺序seed=101/102/103/104/105分别记录。所有记录的新标准化和非线性分位点只用完整train拟合。M1填补/词表继承原完整train，源文件不改。

原/增强表示分别运行主动方安全模型A0/A1和联合安全模型B0/B1。增强仅Alice年龄（UCI）或历史消费/近期性（Hillstrom）的0.25/0.5/0.75分位点hinge；新增坐标零初始化，共有坐标保持一致。原四格优化器不变：lr=0.1、12epochs、batch=512、infeed=4096、DF近似、L2=0.1、投影±10。两个固定本地模型族LR(C=1)与树(100轮/15叶/L2=1)各跑原/新增表示。每任务20安全模型+20本地模型；两方安全份额目录不另算一个模型。完整train扩大同epoch下的更新次数，且分位点重新估计，不能将与预试验的数值差异归因到某一个单独因素。

评价沿用S5.E1定义：UCI ROC AUC为主、AP/Top10%召回/Brier/log-loss为辅；Hillstrom两处理组平均centered Qini为主，逐臂IPW策略价值及top-k增量作诊断。AP不是梯形PR面积。五配对差值A1−A0/B1−B0/B0−A0/B1−A1/合作差异使用共享分层bootstrap（标签或处理×标签），500次验证行和训练seed重采；每seed也有CI。五seed共享完整冻结人群，区间条件于这份训练池，不包含新独立人群或训练集重采。符号翻转p是训练随机性条件检验、假定对称，Holm控制五项主比较；五seed双侧最小p=0.0625，不能提供p<0.05证据。主指标和项目的模型CI不重叠要求均保留，次级指标的正向值不得替代主结论。

## 执行与中断

```bash
python modules/m5_modeling/components/nonlinear_full_vm.py --workspace '/Applications/总文件夹/汇丰/8-9月' --dataset all
```

启动器创建独立queue目录，status.json持久记录pid/current_dataset/completed/status。两个数据集串行运行，端口/证书不会竞争；单个数据集也可用其名称替换all。本轮用独立OS会话启动，控制端日志保留。会话中断后首先检查队列和来宾Notebook，不重复启动同一完整轮；宿主退出码丢失须记录未知，授权工件只恢复到新目录。

每个轮次新建私有目录与双VM本方目录；每次fit在trainings/<条件>_seed<seed>内分code/data/results/logs，保留源码/配置/环境、冻结输入与新矩阵引用、逐epoch完成与训练耗时、结果及日志。数据矩阵、选中（全量排序）记录和分位点在本方VM的data/；不写回原始文件。模型份额留各方，逐记录预测只Alice VM，控制端只导出代码、授权汇总和日志；*.npy/*.npz/model.share/*.trace.log均过滤。完整执行Notebook在私有results/，Public源入口清空输出。读取原测试的能力被去除，不将验证/测试并入训练；完整训练仅指全部原train，完整评价仅指全部原validation。

验收按实际执行源/配置哈希、每方全行保留记录、只读输入、无test、历史入口访问拒绝、非root/无sudo/无宿主挂载、对方SSH拒绝、mTLS负例、预测接收者、逐fit目录、完整epochs/CI/Notebook和宿主私有权限进行。这里仍是可信宿主和半诚实不串通两方的功能模拟；真正PSI、独立确认与输出攻击实验需另验收。
