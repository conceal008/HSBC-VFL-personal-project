# 本地功能模拟运行说明

> 编写日期：2026-10-01 ｜ 版本：v1.0 ｜ 状态：执行说明
> 数据来源：S5.P2 代码、Linux 环境锁、双虚拟机实际运行日志
> 口径基准：共同客户联合营销的公开代理实验；用户授权功能模拟；可信宿主管理员

本轮在两个 Ubuntu Linux 虚拟机中执行隐语两方安全计算。账户、文件系统和权限分离实际生效，但不能抵抗拥有宿主管理权限的人。协议假设为半诚实且不串通的参与方；最终预测仅授权给主动方 Alice。允许释放的预测仍可能携带统计信息，不能用“未传原始数据”推导出绝对零泄漏。

| 模块 | 功能与边界 |
|---|---|
| `functional_vm.py` | 可信环境提供方；按方复制文件，不解析真实数据行；签发证书、限制网络、投递只读代码与输入；每轮新目录，失败也留档。训练后将各方获授权结果导出到对应私有宿主目录，不汇集模型份额。 |
| `functional_tls.py` | 锁定版原生 gRPC 客户端凭证兼容修复；不允许明文后备；实际探测无客户端证书拒绝。 |
| `functional_training.py` | 各方本地训练集拟合缩放器、只处理自己的数据；安全验证预对齐键顺序；CHEETAH 训练、安全预测、保存各方模型份额；终点检查输入和 Bob 输出边界。 |
| `functional_metrics.py` | 仅在 Alice 内运行验证选参、测试指标、配对区间及假设输出释放后的成员诊断；不向 Bob 或联邦驱动返回指标。 |
| `functional_recovery.py` | 仅对已完成但收尾失败的来源，在新目录核对实际输入、处理数组、源代码、候选与预测复制；不训练或重选参数，来源失败状态保留。 |
| `functional_analysis.py` | 已冻结 Alice 评价及获授权预测生成新私有分析 Notebook、逐 seed 图表及事后分数诊断；不读取标签/原始特征或重调参。 |
| `functional_acceptance.py` | 训练完成后的可信管理员文件审核；核对原输入哈希、执行指纹、逐次目录、Notebook、区间和禁止输出；只输出工程摘要。 |
| `S5.P2_local_functional.ipynb` | 各虚拟机实际执行入口；保存代码指纹、过程输出和本方结果；Public 源文件清空输出。 |

模型阶梯为 Alice 单方逻辑回归和梯度提升树候选、安全组聚合特征逻辑回归 L1、安全联合逻辑回归 L3。先完成 L1，再运行 L3；各路线只用验证集选参，固定测试切片。安全 L1 的聚合表不在 Alice 明文落地，因此其成本不能代表原先低成本明文聚合方案。

UCI 使用营销发生前的变量预测响应，不能称为因果增量；Hillstrom 保持两个随机邮件组各自与未发邮件组比较，采用线性 S-learner 的处理组与特征交互。联合模型比较固定的学习率候选，使用裁剪和 L2 正则，五个初始化/批次顺序种子与切分种子分别记录。固定优化轮数避免释放收敛状态。聚合、训练及预测均按块在安全设备内执行，并复用每个 seed 的安全设计块；末批零填充，包含所有真实训练行。分块 FM64 算术环在同种子合成冒烟上与 FM128 参照比较预测误差，验收阈值来自配置；该数值比较不等于加密协议安全证明。输入维度等私有 schema 元数据只保留在执行副本，不发布到 Public 配置。所有指标带自助法区间；同一测试人群上的多个 seed 不等于独立的人群实验。

环境准备以本机 ARM64 macOS + Apple VZ 为依据。两个虚拟机分别为 `hsbc-alice`、`hsbc-bob`；配置见 `configs/functional_vm_template.yaml`，禁止宿主共享挂载。Lima 状态实际位于仓库外 `8-9月/功能模拟环境/lima`，用短路径 `/private/tmp/hsbc-vfl-lima` 指向它，以免 Unix 套接字路径超限。训练账号没有 sudo、交互登录密钥或管理凭证。Lima 管理账号属于可信环境提供方，不能当成参与方。

以下命令从仓库根目录执行。须先完成对应账户的系统安装；证书私钥在本方生成，绝不复制给另一方。

```bash
export LIMA_HOME=/private/tmp/hsbc-vfl-lima
limactl start --name=hsbc-alice modules/m5_modeling/configs/functional_vm_template.yaml
limactl start --name=hsbc-bob modules/m5_modeling/configs/functional_vm_template.yaml
for party in alice bob; do
  limactl copy modules/m5_modeling/configs/linux_environment.lock "hsbc-$party:/tmp/hsbc-secretflow.lock"
  limactl copy modules/m5_modeling/configs/vm_bootstrap.sh "hsbc-$party:/tmp/hsbc-bootstrap.sh"
  limactl shell "hsbc-$party" sudo bash /tmp/hsbc-bootstrap.sh "$party"
done
```

`vm_bootstrap.sh` 是环境安装脚本，不在已有冻结训练目录内重新执行。创建账户、依赖和证书后，使用带 PyYAML/numpy/pandas 的宿主 Python 执行控制端；实际训练由虚拟机 `/opt/secretflow/bin/python` 运行。已有环境不必重复创建。

```bash
python modules/m5_modeling/components/functional_vm.py --workspace ../8-9月 --dataset uci_bank_marketing --smoke
python modules/m5_modeling/components/functional_vm.py --workspace ../8-9月 --dataset uci_bank_marketing
python modules/m5_modeling/components/functional_vm.py --workspace ../8-9月 --dataset hillstrom_email_marketing
```

只有冒烟权限、双方认证和输出检查通过后才允许运行正式数据。三个命令依次执行，不能同时占用同一组联邦/SPU 端口。控制端仅注册已验收的 S1.P2 输入版本，任何输入指纹变化即拒绝。

宿主每轮目录为 `8-9月/功能模拟训练/<dataset>/<round_id>/<party>/`；新增处理数据实际留在本方虚拟机 `/srv/vfl/<party>/<round_id>/data/`。每次训练独立的 `trainings/<model>_<arm>_<seed>_<candidate>/` 保存代码、环境、配置、输入及处理文件指纹引用、结果和日志；不重复复制每个 seed 的相同处理矩阵。模型份额留在各方虚拟机，禁止把双方份额导出到同一控制端。原始下载、旧结果和冻结切片不修改。

没有运行真实客户 PSI。本轮是已冻结预对齐样本的功能实验，在 MPC 内仅公开键及顺序是否一致的布尔结果。真实业务实体匹配、交集披露裁定、恶意参与方攻防、生产密钥生命周期以及全部属性/模型反演攻击仍需后续验收；本步骤不能将这些项标记为通过。


训练完成后，用控制端 Python 执行文件验收（`<本轮目录>` 与 `<新验收文件>` 必须指向仓库外私有位置）。验收文件拒绝覆盖；失败不构成通过。验收工具读取 Alice 获授权的评价文件与本方输入字节哈希，不读取两方原始数据行。

```bash
python modules/m5_modeling/components/functional_acceptance.py <本轮目录> --workspace ../8-9月 --destination <新验收文件>
```

完整效果和解释边界分别见各轮 Alice 的 `results/private_evaluation.json`、`results/party.executed.ipynb` 与新建分析报告；公共 [工程验收说明](本地功能训练工程验收.md) 不包含数据效果指标。

最终连续近似修正轮使用隐语原生 DF、MPC 分块权重投影与原分数范围检查，Alice 落盘前检查有限性及预声明的训练端点限值。SPU 协议 trace 禁止开启和导出。数值异常整轮失败，无明文后备。合成算术参照允许 `--smoke --arithmetic-reference FM128`，真实数据轮不能通过该选项改位宽。

结果分析入口（只有通过轮次可执行，每次新目录，不覆盖旧输出）：

```bash
python modules/m5_modeling/components/functional_analysis.py <已通过的私有轮次目录>
```

分析 Notebook 位于该轮 Alice 的 `results/analysis_*/结果分析.executed.ipynb`；各次 Restart & Run All 生成新的 `outputs_*/` 报告与图，不改冻结模型或评价。

新分析目录自身700、文件600；每次 Run All 的新输出也收紧权限，仅触碰本次新建分析树，不改原输入、模型或冻结评价。
