## 主要结论

- 编码组合层面不满足 k-匿名：训练发布中约 5.4% 的行所在组合不足 10 位不同客户。
- 单次发布平均 16.2 个字段（14–20）可被几乎确定地推出，持有者被确定推出的比例字段平均 59%；L1_k10 只有 1 个字段（由年龄决定）。
- 精度与披露同升同降；组合级 k-匿名抑制精度代价很小，但对已识别客户的字段推断作用有限。
- 3 棵深 3 是值得另行预注册的折中候选（内层验证比 L1_k10 高约 0.03，可确定推出约 7 个字段）。

## 适用边界

- 内层验证集也用于 S5.G1 的调参与 B_best 选择，权衡表数值偏乐观，只作变体间的相对比较；开发评估集上没有评估任何新变体。
- 逐字段 AUROC 对极稀有字段不稳定，同时看持有者被确定推出的比例。
- 编码表、树结构、客户号与逐行推断只在维护者本机或会话私有目录，不入仓库。
