## 二、判据层级

| 层级 | 回答什么 | 判据 | 来源 |
|---|---|---|---|
| 最终判据 | 联邦名单是否带来增量转化 | 随机分组试点的相对增益 ≥ 20%，双侧 α = 0.05，功效 0.8 | DR-MX-001 · D-1、D-4；S0.1 |
| 诊断与选型 | 离线排序能力是否可分辨地不同 | 第三、四节的配对比较 | DR-MX-002 · D-1、D-2 |
| 值不值得做 | 盈亏平衡点是否现实可达 | S6.P2 的盈亏平衡命中提升，需求方确认 | 框架 S6.8；任务清单 T2 |

离线 AUROC、Lift@K 的提升**不等于**增量转化；报告中不得把离线排序指标的差异写成「增量」或「收益」。

## 三、离线配对比较

1. **配对**：两臂使用同一冻结测试集（按客户去重）、同一组训练 seed、同一调参预算。
2. **seed 数**：≥ 6。少于 6 个时不得使用 seed 级符号翻转检验（5 个 seed 的最小双侧 p 为 0.0625）。
3. **重抽样**：两层——外层有放回重抽训练 seed，内层按客户簇做 Poisson(1) 权重 bootstrap（同一组权重同时作用于两臂与全部 seed）。正式比较 B ≥ 2000。簇默认是客户；同一家庭或同一推荐链的客户存在关联时，簇须在预注册时改为更粗的单位。
4. **区间与 p 值**：配对 AUROC 差的 95% 百分位区间；双侧 p = 2 × min(P(差 ≤ 0), P(差 ≥ 0))，上限 1。实现：`components/paired_eval.py` 的 `paired_bootstrap`。
5. **旧判据一栏**：同时报告前 5 个 seed 上两臂各自区间是否重叠，只作与历史结果对照，不作判断依据。
6. **seed 级符号翻转检验**：只回答「在这一份测试集上」训练随机性能否解释差异的条件问题，**不得用于总体结论**。S6.P1 显示两模型总体一样好时，6 个 seed 的符号翻转拒绝率约 0.8。
7. **多重比较**：每次预注册指定**一个**主对比（G3 中为 L3 对 L1）。其余对比为次要对比，p 值用 Holm 法校正，并在报告中标明。

## 四、可检出差异与结论措辞

- **可检出差异**：`detectable_gap(..., method="conservative")`，即下面两者取大：
  - 配对差的重抽样标准误 ×（z₀.₉₇₅ + z₀.₈）；
  - 重抽样估计的两臂相关系数代入 S0.1P 闭式近似。
  理由（S6.P1）：正例约 150 个时，重抽样标准误在备择下偏低约一成（偏乐观）；正例较多时闭式近似偏保守。取大者在两档都不乐观。
- **四种结论**（`verdict`），按顺序判断：

| 条件 | 结论措辞 |
|---|---|
| 区间下界 > 0 | 可分辨的提升 |
| 区间上界 < 0 | 可分辨的下降 |
| 区间含 0，且可检出差异 > 预注册的关心尺度 | 未达可检出规模 |
| 区间含 0，且可检出差异 ≤ 关心尺度 | 在预声明尺度上无可分辨差异 |

- 「未达可检出规模」不得写成「无差异」，也不得写成「有差异」。
- 统计上可分辨、但相对提升小于 20% 的差异，按「无实际差异」报告（DR-MX-001 · D-4）。

## 五、规划所需正例

- 预注册时写明测试集正例数（按客户去重）与第四节的可检出差异预估。
- 规划用表：`results/s6p1_positives_simulated.csv`（模拟法，备择设定）：检出 0.02 约需 693 个正例，0.03 约 293 个，0.01 约 1,773 个；蒙特卡洛误差带约 ±16%（95%）。它替代 S0.1P `offline_auc_positives.csv` 的规划用途；后者不改。
- 数据到手前用 S0.1P 闭式近似粗估时，两模型估计相关**取 0.7，不取 0.8**。S6.P1 中两个系统误差相互独立的模型相关约 0.69；按 0.8 规划会低估所需正例。
- 测试集正例达不到关心尺度所需的数量时，预注册须提前写明「本比较只能检出 ≥ X 的差异」。

## 六、阴性对照与封存确认集

- **阴性对照**：任何「L3 优于 L0 或 L1」的结论，须附同一调参预算下的阴性对照——在对齐客户内打乱被动方特征行、保留边际分布。阴性对照的配对差区间应含 0；若不含 0，说明增益来自容量或调参而不是信息互补，主结论作废（DR-MX-002 · D-5 ③）。
- **封存确认集**：只在预注册的决策写定后打开一次，结果按第四节措辞原样报告，不再调参重跑。

## 七、校准证据（S6.P1，纯合成打分）

合成设定：潜变量 z ~ N(0,1)，y ~ Bernoulli(sigmoid(c + 2z))，正例率 10%；模型打分 = z + 系统误差（模型级、各 seed 共享）+ seed 误差 0.1。模型 A 总体 AUROC ≈ 0.845。

| 检验 | 结果 | 结论 |
|---|---|---|
| 零效应下新判据的第一类错误率（400 次） | 150 正例 0.038；441 正例 0.045 | ≤ 0.07，D-1 推翻条件**未触发** |
| 零效应下 6-seed 符号翻转的拒绝率 | 0.81、0.80 | 条件检验，不能下总体结论 |
| 以 S0.1P 预测差距为真时的功效（300 次） | 150 正例 0.773；441 正例 0.880 | 441 档超出 [0.707, 0.879]，D-2 推翻条件**触发** |
| 旧判据（5 seed）功效 | 0.12、0.10 | 旧判据功效过低 |
| 重抽样标准误 / 真实标准差 | 零效应 1.03、1.06；备择 0.89、1.03 | 备择 150 档略低于 0.894，故第四节取两法较大者 |
| 模拟法所需正例（备择） | 0.02：693；0.03：293；0.01：1,773 | S0.1P 默认相关 0.8 时 0.02、0.03 两档少估约三成；相关 0.69 时偏保守 |

D-2 触发后的处理按其预先写定的后果执行：用模拟法重算所需正例。两处判据（标准误比值区间、取两法较大者）是在第一次、第二次运行之后加入的，配置文件中已注明先后；它们都由 D-2 的同一阈值（所需正例偏差 ≤ 25%）换算而来。

## 八、已知局限

1. 校准在打分层面的合成设定上做，不训练模型。D-1 原文要求的「M2 零效应合成设定」复核属于实验，留待恢复后补一次。
2. 合成设定只有一种误差结构（两模型系统误差相互独立）。真实的两臂共享大部分特征，相关通常更高，所需正例会更少；以那一次比较自己的重抽样结果为准。
3. 簇定义默认客户相互独立；家庭或推荐关系造成的关联若未在预注册中处理，区间会偏窄。
4. 本口径只覆盖二分类排序比较与随机对照的增益检验；Qini、AUUC 等增量指标的区间方法沿用 `components/metrics.py`，下一版补校准。
