攻击者设定为**诚实但好奇的协议内参与方**，不假设外部窃听。

**九类攻击**：A1 残差标签推断 · A2 嵌入反演 · A3 梯度标签推断 · A4 特征推断 ·

威胁模型：**半诚实 + 部分恶意**（S7.4 起放开了半诚实假设）。

**核心结论**：

1. **不加防护时标签完全泄露**（A1 泄露 AUC = 1.0000）。首轮权重为零、预测恒为 0.5，
   残差 `r = 0.5 − y` 的符号与标签一一对应。
2. **逐轮加高斯噪声不是有效防护**（本步骤的证伪推翻了自己的初期读数）。
   噪声轮间独立而标签恒定，跨轮平均即可消掉：σ=1.0 时泄露 AUC 回到 1.0000。
   要压到 0.67 需 σ=30，此时可用性 0.6352 **低于 L0 基线 0.7089**。
   → 可行路径只能是协议级手段（安全聚合 / 同态加密 / 秘密分享）。
3. **「冻结编码器 = 更安全」是错的**。形态B 挡住了梯度标签泄露（1.00→0.50），
   但特征反演风险反而更高（R² 0.667 > 形态A 的 0.488）。
   它换掉的是标签暴露面，不是特征暴露面。

> **降级说明（W-002）**：ε 为**单轮**高斯机制预算，未实现 RDP 会计与子采样放大，
> **不可作为差分隐私保证引用**。未覆盖特征推断攻击、成员推断攻击与恶意参与方设定。

## S7.3 补充（2026-09-03）：特征推断与成员推断

| 产出 | 位置 |
|---|---|
| A4/A5 攻击实现 | `components/attacks.py` |
| 特征推断与上行防护 | `results/feature_inference.csv` · `feature_inference_stronger.csv` · `uplink_defense_utility.csv` |
| 成员推断 | `results/membership_inference.csv` · `membership_capacity.csv` · `membership_lira.csv` |

**三条新结论：**

1. **无防护时特征被精确恢复**——只要辅助样本数达到特征维数（本例 6 个），
   主动方即可反解被动方全部原始特征（R² = 1.000000）。
   加上 A1 的标签完全泄露，**无防护的纵向联邦逻辑回归是双向完全泄露的**。
2. **上行加噪是有效防护，与下行加噪的结论完全相反**。σ=0.1 使特征 R² 从 1.00 降到 0.20，
   可用性仅损失 0.0014。机制：A1 的信号轮间恒定可平均消噪，A4 依赖病态线性系统
   （条件数约 4.8×10⁴）的精确解，噪声被放大五个数量级。
   → **防护必须逐攻击面评估，不能一刀切。**
3. **成员泄露由模型容量驱动，与是否联邦无关**（L0/L1/L4 均为 0.510；
   GBDT 深 3→6 为 0.528→0.545）。

**方法论要点**：朴素的损失阈值成员推断攻击**没有通过有效性验证**——
在训练 AUC = 1.0000 的模型上也只到 0.52。据此宣称「无威胁」会重蹈覆辙，
故改用 LiRA 式影子模型校准并重新验证。

> **降级说明（W-002）**：A5 用 32 个影子模型（LiRA 原文通常 64–256），
> 数值应读作该设定下的**下界**。A4 只针对联邦逻辑回归，
> 纵向 GBDT 的专门特征推断攻击尚未实现。

## S7.4 补充（2026-09-04）：恶意参与方

半诚实假设在真实场景中往往不成立——**协议由代码执行，而代码由某一方控制**，
对方无从验证收到的数字是不是真按协议算的。

### 🔴 C10 · 两项防护必须同时开启，缺一个另一个就失效

| 防护组合 | 攻破 σ=0.1 所需成本 |
|---|---|
| 只加噪（幅度不受约束） | 幅度 1000 时**仅需 100 次重复** |
| 只查合法性（无噪声） | 伪装探针 R²=0.859，**26 次全部未被标记** |
| **两者同时** | 合法幅度下需约 **10⁸ 次重复**，实际不可行 |

机制：单次探针的信号量级是 `lr·amplitude/n`，噪声固定为 σ——**信噪比与幅度成正比**。
约束幅度的唯一手段就是残差合法性检查。

→ **合法性检查把攻击成本抬高六个数量级。它不是锦上添花，是让加噪防护有意义的前提。**
**这条此前不在 M8 的防护基线里——是本步补上的自身漏洞。**

### C11 · 恶意被动方可操纵名单

幅度 1.0 时 45% 的目标客户被顶进 Top-10% 名单，而名单重合度仍有 0.93——
**高于旧阈值 0.9，不会告警**。M8 基线已据此收紧到 0.95。
但这只是检测手段，不是防护；根治需可验证的部分 logit（零知识证明类），本阶段未实现。

## S7.5 补充（2026-09-04）：模型窃取与信息累积

### 🔴 C12 · 被动方可独立复现整份名单

推导完全建立在已证的 A1 之上：能推断标签 → 反解 logit → 减去自己的 partial_b
→ **得到主动方的全部贡献，逐样本**。后果不是「偷到几个参数」，
而是**被动方可以不依赖主动方独立出名单**——商业资产的直接转移。

| 下行 σ | 标签推断准确率 | 名单复现重合度 |
|---|---|---|
| 0 | 1.0000 | **1.0000** |
| 1.0 | **1.0000** | 0.126 |
| 3.0 | 0.9994 | 0.104 |

**一个有用的不对称**：σ=1.0 时标签仍被完全推断，但名单复现已跌到随机水平。
机制——标签只需残差的**符号**（轮间恒定，可平均恢复）；
模型窃取需要残差的**精确数值**（随训练变化不可平均，且量级只有 O(正样本率)=0.03）。

→ **不要因为「噪声防不住标签」就不加噪声。** 它保的是模型资产，且代价近零。

### C13 · 多次建模累积：不构成威胁，但前提很关键

合法幅度 + σ=0.1 下，6000 次重训（约每天重训 16 年）仍未攻破。
**但这个「安全」完全依赖残差合法性检查在场**——幅度不受限时 100 次即可。
已配对照实验单独验证，避免把「攻击太弱」误读为「防护有效」。

> **仍未覆盖**：多方合谋、模型窃取的黑盒查询变体、攻击者篡改自身模型结构。
