# S-GOV.14 主分支实验同步声明

> 编写日期：2026-10-09 ｜ 版本：v1.0 ｜ 状态：执行前声明
> 数据来源：既有实验源码、配置、模块台账、公开工程验收及私有日志路径
> 口径基准：用户最新要求先同步main再开展后续实验；Public数据纪律

will_produce:
- 一份逐轮实验方法/核心代码/Notebook/工程结果与私有指标位置索引；README当前入口和进度状态更新。
- 每轮结果留痕规范、当前实验结果位置清单、主分支发布判决和发布回执；保留失败及负结果。
- 完整仓库门禁通过后，同步既有逐步骤提交与本步骤到远端main，核对远端SHA、文件及祖先关系。
will_not_produce:
- 不启动新的模型或攻击实验，不改变训练数学、切分、配置及冻结结果。
- 不向Public提交真实数据及其派生数值、交集规模、预测、权重、份额或私有执行输出。
- 不把未执行的其他候选或独立人群确认写成完成，不把main同步当作业务/安全验收。
success_criteria:
- 每个当前实际实验可从README直接进入方法、核心函数、Notebook与结果日志；设计/合成/实际执行/阻断明确区分。
- 一步一提交、完整门禁、数据审查、系统日志和交接完成；远端main包含全部本轮发布提交。
risk:
- 草稿PR曾长期堆叠，main落后；仅Git快进同步可保留原有逐步骤提交，禁止force push。
- 公开指标与本仓库数据纪律冲突时以私有完整结果日志+公开索引留痕，不为填日志而披露受限内容。

编号补记：原暂编S-GOV.12；集成main后发现该号已用于9月治理步骤，现更正为S-GOV.14。工作范围、先行声明与数据边界不变，不覆盖旧编号或旧日志。
