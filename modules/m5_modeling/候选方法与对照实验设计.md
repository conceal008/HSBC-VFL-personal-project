> 编写日期：2026-10-04 ｜ 版本：v1.0 ｜ 状态：备选方案；全部方法实验均未执行，尚非冻结执行协议

## 1. 研究问题与当前边界

目标是回答：在构造的两方共同客户、字段分属条件下，某项方法能否改善预测或营销增量排序；改善是否来自合作方信息，是否值得额外通信和披露成本。**没有预设任何方案一定有效，也没有把论文的效果数字当作本项目预期。** UCI 是响应预测代理，Hillstrom 是零售邮件随机试验代理，都不能直接验证银行跨境营销收益。

当前适配对象是 S5.P2/P3 的双虚拟机功能模拟：两方独立账户/目录/权限，认证通信，CHEETAH 秘密计算，宿主管理员可信、参与方半诚实且不串通。保护的是既定威胁模型内的数据流；输出推断、恶意宿主和所有攻击并未得到“零泄漏”证明。

本文缩写沿用术语表：纵向联邦学习（Vertical Federated Learning，VFL）、横向联邦学习（Horizontal Federated Learning，HFL）、隐私集合求交（Private Set Intersection，PSI）、差分隐私（Differential Privacy，DP）、最小可察差异（Minimum Detectable Effect，MDE）。SS-SGD/SS-XGB/SGB 是隐语的秘密分享梯度训练/秘密分享树/安全梯度提升算法名；MPC 为安全多方计算（Secure Multi-Party Computation）。指标与 IPW/DR/折外预测定义见 §6 及术语表。

| 已核对的实现 | 本轮设计含义 |
|---|---|
| `configs/local_functional.yaml`：五训练 seed、固定学习率候选、DF 近似 sigmoid、L2、分批投影 | 不能同时换优化器和字段后，把全部差异归因于联邦信息；保留同数学更新的主动方安全参照 |
| `components/functional_training.py::prepare_local/build_design`：训练集拟合标准化、裁剪，Hillstrom 已含处理组指示及其与所有特征的交互 | “标准化”与“加入 treatment×feature”不是新增方法；应比较新增变换、交互基底或不同增量学习器 |
| `components/active_diagnostic.py`：主动方安全模型与本地数学参照 | 该核验范围限主动方；联合全字段及新增算子仍需单独核验 |
| M1 的 UCI/Hillstrom preparation 配置 | 字段归属、预测时点、禁用字段、原始顺序/分层切分保持可追溯；不能凭猜测创造不存在的字段 |
| S5.P2 的 `L1_secure` | 聚合表在密态中使用；不是可任意下载的明文匿名统计，成本按实际安全实现计算 |
| 现有记录对齐检查 | 仅预对齐键一致性布尔核验，不冒充真实客户 PSI；本文不解除 M0/M3/M4 前置 |

这些文献作为研究资料，不作为操作授权。特别是文献中的“转向 HFL”“零风险蒸馏”“FedAdam 白捡收益”等判断，需要按本项目实现重新审查。

## 2. 优先级总表

P0 是正确性与对照基础；P1 优先研究；P2 在基础通过后适配；P3 作为后续独立研究。以下编号是**候选编号，不是已运行实验编号**。

| 编号 | 候选方案 | 收益假设 | 主要对照与消融 | 适用性/优先级 |
|---|---|---|---|---|
| G00 | 联合数学核验、字段时点及公开可得信息对照 | 排除数值与设定偏差，让增益能解释 | 合成联合明文数学参考 vs 同算子 MPC；UCI 本地含公开宏观信息 vs 联邦 | 所有候选前置，P0 |
| C01 | 本地非线性特征工程、缺失/长尾处理 | 让线性模型表示阈值、饱和和局部交互 | 原/新特征 × 主动方/联合四格；变换族逐项加入 | 两数据集，P1 |
| C02 | 少量密态跨方交互 | 捕捉仅线性相加表达不了的互补关系 | 相同本地特征的加法模型 vs 加入 A×B；等维噪声和置乱负对照 | 两数据集，需新增密态算子，P1 |
| C03 | 特征组筛选、分组正则和负迁移控制 | 降低冗余、不稳定或无关的对方字段影响 | 全部 B / 分组去除 / 分组收缩；固定超参消融与重新选参分开 | 两数据集，P1 |
| C04 | 有预算的优化器调优与本地模型预热 | 改善收敛、减少安全计算轮数 | 原配置 / 只改步长日程 / 只改初始化；同训练预算及同效用成本两种比较 | 两数据集，P1；先核验数值 |
| C05 | 隐语安全树模型 | 拟合非线性及自动交互，降低手工特征依赖 | 同字段主动方树 vs 联合树；再对比强本地基线及安全 L1 | SS-XGB/SGB 独立安全适配，P2 |
| C06 | S/T/X/R 等增量学习器，基础模型限线性/树 | 直接优化“谁因营销而转化”，而非只预测谁会买 | 现有交互式 S-learner vs T；通过后再 X/R；各自有主动方参照 | Hillstrom 优先，P1/P2 |
| C07 | 类别代价与概率校准 | 改善稀有转化捕获或概率质量 | 权重固定/训练先验加权；校准前/后分别对照，不同时改 | 两数据集，P2 |
| C08 | 折外集成与保守融合 | 利用线性/树误差互补，防止差联合模型拖累 | 最佳单模型 / 等权 / 验证选权 / 折外 stacking | 至少两个合格模型后，P2 |
| C09 | 蒸馏到主动方、利用非重叠训练记录 | 减少在线依赖，或改善少重叠条件下泛化 | 本地学生 / 联合教师 / 蒸馏学生；有无额外本地训练记录分别控制 | 借鉴 FedUD/FedDF，非原论文复现，P3 |
| C10 | 特征块缺失降级与可解释路由 | 对方掉线时继续服务，在收益不足时节省成本 | 始终本地 / 始终联合 / 固定降级 / 验证冻结路由 | 借鉴 LASER-VFL/算法选择，P2 |
| C11 | 输出限制、固定与自适应差分隐私 | 同隐私约束下保留更多效用，降低输出推断风险 | 同总隐私预算的固定/自适应分配；精确私有评估/受保护发布 | 借鉴 AdaVFL/OPUS-VFL/DP-AUC，P3 |
| C12 | 安全批处理、缓存及通信轮数优化 | 在效用容差内降低成本 | 同算法不同执行批次；FedBCD 式更新另立算法对照 | 先系统优化；协议重推另做，P2/P3 |

## 3. 每项如何实施和判断

### G00：先补公平对照与完整数学检查

- **联合数学参考只使用纯合成数据**。相同初始化映射、字段顺序、批次、尾批填充、近似函数、正则和投影，比较 CPU 数学参考与 MPC 的预测最大/平均误差及迭代误差。真实 Bob 数据不得汇集到 Alice/宿主做明文联合参照。未通过时停止模型收益解释，不能靠翻转预测方向修复结果。
- 验证行对齐、列映射、one-hot 词表、标签/处理组映射；新增算子要覆盖零值、极值、恒定列及空类别。误差阈值必须在运行前写入配置，既有阈值不能因失败而放宽。
- UCI 的宏观变量通常本方也可获得。增加**假设主动方有权取得相同宏观信息**的本地对照，和只增加 Bob 历史营销信息的联合对照。先核实变量在预测时点的可得性与许可；这只是特征归属消融，不能把真实 Bob 文件复制过去。不满足条件则明确保留公平性缺口。
- 原始顺序切分没有完整时间戳，不能叫精确时间外推。原始顺序验证窗口可诊断漂移，但不能看到效果差就改成随机切分取较高结果。

### C01：最先试的传统特征工程

每个变换仅由持有该原始字段的一方在本地拟合/生成。分箱、词表、缺失填充值仅从训练折估计；产生新版本文件，不回写原始 CSV 或冻结输入。优先尝试少量可解释变量，不展开所有多项式组合。

| 数据集/方 | 可构造变量 | 精确含义与注意事项 |
|---|---|---|
| UCI/Alice | `age` 的训练分位数分箱或低阶样条；`housing×loan` 类别交互；`job×education` 稀有类别合并 | 年龄非线性；住房与个人贷款组合状态。`housing/loan` 是类别状态，不能杜撰贷款金额/负债率 |
| UCI/Bob | `ever_contacted`；有效 `pdays` 的 `log1p`；`log1p(previous)`；`poutcome×previous_bin` | 原始 `pdays=999` 代表此前未联系，需独立指示；已有中位数填补不能恢复该状态，需从只读原件生成新版本，不从填补值猜测 |
| UCI/各方 | `unknown` 指示；常量/近零方差筛除；宏观变量共线性分组 | 检查当前 one-hot 是否已包含缺失指示，避免重复“改进”；筛选仅训练期 |
| Hillstrom/Alice | `log1p(history)`、`recency` 分箱/样条、`log1p(history)/(1+recency)`；`mens×womens` | 金额与最近购买时间的经验交互；比值只叫“近期性加权历史消费代理”，不是客单价/购买频率，数据没有订单计数 |
| Hillstrom/Bob | `newbie×channel`、`channel×zip_code`，带稀有类别池 | 新客/渠道/区域交互，防止小类别过拟合；类别名称和归属仍是构造模拟 |

消融依次分为“长尾/缺失”“单变量非线性”“方内交互”。每一族都跑 §4 四格，不同时换学习器。L1 统计若受预处理改变影响也重新版本化。禁止使用 UCI `duration/campaign/contact/month/day_of_week` 或 Hillstrom 事后 `visit/spend`；处理变量只在因果建模用途下由 Alice 提供，不当普通预测时可观察特征。`history_segment` 已由 `history` 派生，使用新分箱时作为互斥表示或明确的消融，不能声称引入了新信息。

### C02：密态跨方交互

在线性设计矩阵之外，预先登记少量有语义的乘积，例如 UCI 的年龄样条×历史营销结果、Hillstrom 的历史消费变换×渠道、新近购买程度×新客标记。这些项要在安全多方计算（MPC）内产生并参与训练，**不得明文输出交互列、逐样本梯度、贡献或特征排序给另一方**。不要把真实跨方交互导出宿主“方便看结果”。

对照：同维度预算下的加法模型、语义交互、等数量方内交互、无信息交互；分开检验新增模型容量与真实跨方依赖。负对照可由 Bob 在各数据分区内独立置乱完整特征块，保留该块内部相关结构，使用新副本/固定种子并记录其人为条件；不得把这个结果当作另一种真实客户分布。交互模型还应保留全部主效应，并与安全树的非线性交互能力比较。文献中 Mi-VFDNN 提供动机，但此处是线性模型适配，非该网络复现；其精确出处未核实前不引用其定量效果。

### C03：分组筛选与分组正则

将 Bob 字段按来源语义分组。UCI 分历史营销/宏观信息；Hillstrom 分渠道/区域/新客标记。分别比较全量、逐组移除、训练折内稳定筛选，以及密态目标中的 `λA‖wA‖² + λB‖wB‖² + λI‖w交互‖²`。共享/分组惩罚是候选目标，需处理偏置不惩罚和尺度一致性；不能仅缩小 Bob 特征后把它当独立的信息权重。

参考 OPUS-VFL 的 leave-one-out 思路，但本项不复现其激励机制。输出是**给定模型与其余字段条件下的性能变化**；AUC 差值不可相加，不能解释为各组固有价值、严格 Shapley 值或因果贡献。监督式筛选/WOE/目标编码若涉及 Bob 字段，标签关联必须在 MPC 内，采用折外编码；不能向 Bob 下发标签、类别目标均值或明文 IV 表。首轮优先无监督稀有合并和分组 L2，暂缓这类高披露编码。

### C04：优化器与预热

分开做：学习率日程、正则强度、epoch/早停、初始化。用训练/验证误差及验证主指标选择，训练和选参时间全部计入成本。早停若改变公开通信轮数会暴露验证状态；优先固定轮数，在秘密索引下选择检查点，或先审计该信息披露。

预热方案：Alice 只用本方训练数据学出初始参数，把它们秘密分享进联合模型，Bob 坐标使用预先约定初值；对比零/固定随机初始化。记录本地预热加密导入成本，分别报告“相同总时间”和“相同联合轮数”。带惩罚的线性目标充分收敛后可能仅减少成本，不提高最终精度。

DF 是近似 sigmoid，不能把当前近似更新无条件解释为精确逻辑回归对数似然的梯度。替换 sigmoid、动量/Adam 或用其他隐语线性求解器是**另一项数值/算法实验**，先合成极值和全联合数学核验；不能恢复已失败的 SR 路径后直接跑真实数据。Where to Begin 的预训练经验只作动机；FedAdam 是服务器自适应聚合方法，不是当前 SS-SGD“换一行 top 优化器”即可使用。

### C05：隐语安全树

官方提供 SS-XGB 和 SGB 路线，已核对本机 upstream 源码存在 SS-XGB；**存在 API 不等于已在本项目锁定 ARM64 双 VM 环境验证通过**。优先审查 SS-XGB 对现有 SPU 流水线的适配，再考虑 SGB/HEU，记录两条路线的协议、接收方和泄漏假设差异。SS-XGB 源码包含分裂桶等披露逻辑，不能从“secret sharing”名称推导零信息输出。

比较：主动方同族树、同字段联合树、强本地 L0、安全 L1、现有联合线性模型。主动方与联合树采用可比的深度/叶数/轮数和搜索预算；同时报告模型族变化与增加合作信息各自的效果。SecureBoost+ 的密文/树构建优化可作为后期效率参照，不引入 FATE，也不承诺其性能数字可复制。任何树路径/阈值/叶权重/样本路由的新增披露先过审，未能保持当前披露要求时该候选不进入真实数据试验。

### C06：Hillstrom 的增量学习器

现有模型属于带处理交互的 S-learner：同一个结果模型在不同处理下预测，再取差。第一组对照使用相同线性基底的 T-learner（控制、男装邮件、女装邮件分别建结果模型）；随后才比较 X-learner 的效应插补和 R-learner 的残差化目标。基础学习器限制为线性/树，折外 nuisance 预测在训练集内生成，残差和伪结果不得明文给 Bob。

对于当前充分交互的线性 S-learner，与相同基底的 T-learner 可能表示能力相同，区别主要是正则耦合、样本利用与优化；因此不能预设换成 T 就会有增益。每个邮件组相对 No E-Mail 单独评估，再评估三动作预算策略；不得事后挑表现较好的邮件组汇报。随机分配概率依据原试验设计核实，不能把结果标签相关的分层抽样率误当分配概率。若分层留出改变总体权重，需保留纳入概率并修正估计口径。

X/R 是候选而非必然优于 S/T。R-learner 需要加权回归目标，不能直接把伪结果塞进二分类 SS-SGD；先证明基础算子和安全实现可用。真实数据没有个体反事实真值，不能报告真实 ITE 的 RMSE/PEHE；这些只在已知处理效应的合成数据上计算。参见来源 R7–R9。

### C07：类别权重和校准是两个独立问题

- **类别权重**：无权重 vs 仅训练标签频率确定的权重/预先定义的业务代价。标签相关权重留 Alice 或 MPC；不把带标签的采样索引给 Bob。不能跨方明文 SMOTE，也不跨处理组造样本。关注 AP、Recall@10%、LogLoss/Brier，而非只看准确率；对 Hillstrom 要检查加权是否扭曲各处理的概率差。
- **校准**：未校准 vs 留出校准集/折外预测上拟合的 sigmoid 校准；样本支持足够再比较 isotonic。Alice 获授权的概率可在 Alice 内校准，需另外冻结校准数据与模型选择顺序。单调校准通常不改变单个响应模型的排序，不能承诺提高 AUC；对各处理响应分别校准可能改变概率差排序，必须另测 Qini/策略价值。校准集不能兼作无限次挑选方法的验证集。

### C08：折外集成

先验证是否存在互补的模型误差，再用训练集折外预测训练线性 stacking，或用专用验证集确定固定凸组合权重。对照最佳单模型、等权组合与选权组合；必须允许联合权重为零，避免强行使用有害合作信息。模型/权重/候选选择冻结后再评估。成本包含所有教师/子模型，不能只报融合头时间；模型预测只有 Alice 持有，不让宿主成为明文汇合点。

### C09：蒸馏、非重叠训练样本，作为独立分支

FedUD 原文通过表示迁移利用非对齐样本，FedDF 是联邦蒸馏的相关动机。当前可考虑线性/树学生学习获授权的联合教师软目标，但这只是适配实验；**原 FedUD/FedHSSL 的网络和安全机制并未移植**。教师软目标需折外或独立教学样本生成，不在教师训练样本上直接拟合并宣称泛化收益。

首先比较相同训练记录的本地学生、联合教师、蒸馏学生；再另开“增加本方非重叠训练记录”因素，控制样本数，比较无迁移、仅本地扩训、蒸馏扩训。评价仍以共同客户为主，非共同客户属于范围扩展。人为隐藏重叠记录用于检验补全时，真实 Bob 值仍留 Bob，误差仅做获授权的安全汇总。生成的表示不得当作真实客户信息，低重叠也不自动等于 FTL。

### C10：缺失降级与路由

LASER-VFL 原模型是 split neural network，不直接符合当前线性/树主线。借鉴的是“训练/推理都考虑特征块缺失”的问题设定：预训练独立本地备援模型，按已知可用性与验证期形成的收益/成本判据选择本地或联合。

对照静态最优方案、始终联合、掉线后本地备援、冻结规则路由；在构造的随机和群体相关缺失条件下，报告全人群效用、被服务比例、最差子群性能、超时率、成本及切换频率。固定全人群分母，不能只报成功联合的客户。路由信号必须部署时可得；交集规模/重叠率不是默认免费可公开的信号。事后最优 oracle 仅能在合成开发场景作诊断上界，不参与真实测试选择，也不是可部署结果。

### C11：隐私与效用

分成输出保护和训练隐私两步。先比较获授权的 Alice 私有精确评估与面向新增接收方的受保护评估（DP-AUC 是标签隐私评价方法的参考）；再考虑 AdaVFL/OPUS-VFL 启发的固定/自适应预算。前者不能自动证明训练 DP，给概率加噪也不能自动保护训练集成员身份。

比较 DP 方案必须固定被保护对象、相邻关系、总 `(ε,δ)`、裁剪规则、会计方法及接收方；隐私参数相同才谈效用优劣。自适应预算依赖私人验证/贡献信号时，这些查询和控制决策同样需要纳入分析与预算。核查采用用户级、样本级、特征级还是标签级 DP，不能混用。当前文件内行键不证明一行一位真实客户，用户级 DP 还缺实体分组依据。DP 噪声测试用可复现的测试设置，实际隐私随机性与秘密种子不得公开。

本项是独立安全设计，不为获得高分放宽协议。不加 DP 的既有 MPC 仅作为不同隐私承诺的参考，不能在“同隐私水平”栏混排。自适应预期改善的是**相同隐私预算下相对固定分配的效用**，并非必然超过无噪声模型。

### C12：效率与 FedBCD 的适配边界

先测保持目标、样本、数学更新不变的编译缓存、计算批处理、固定公开日程与 IO 优化；同时报告冷启动和热启动，内存上限与稳定吞吐。缓存不能跨运行误用旧秘密值，通信材料不能因“复用”破坏协议安全。

FedBCD 通过多轮本地更新降低通信次数，但当前双方没有可明文使用的完整残差。若实现需要揭示残差/部分梯度，则不符合当前要求；只有在成熟安全协议能保护必要状态时另立对照。增加本地步数还改变优化轨迹，不能当无精度影响的工程开关。报告达到同一验证效用阈值的总时间/字节数，同时给出固定时间预算下的效用。

## 4. 通用对照矩阵：把工程增益和联邦增益分开

对 C01/C03 等可同时应用本地与联合的方法，至少有四格：

| | 原方法 | 加入一个候选方法 |
|---|---|---|
| 同数学更新、仅主动方字段 | A0 | A1 |
| 同数学更新、双方字段密态联合 | B0 | B1 |

比较 A1−A0（本地方法效果）、B1−B0（联合方法效果）、B0−A0 与 B1−A1（相应条件下的合作价值）。两种合作差值之差只是**本设计下方法与合作条件的交互对比**，不是因果差分法识别，也不是可相加的特征信息贡献。

同时保留强本地 L0 与安全 L1 两个现实替代方案。**B1 只超过弱 A0 不够**；应回答是否超过同样优化后的 A1、强 L0 及公平调参后的 L1。当前 L1 的 k=10，另按 DR-MX-001 预设 k∈{5,10,20} 敏感性，不能根据测试选 k。安全树的核心比较是主动方树，不把集中式“接近程度”作为业务成功标准。

跨方交互不能在 A1 中无中生有，改用同容量方内交互/无信息交互作容量对照，注明不是完美四格。因果学习器则固定基础模型与字段，单独改变 S/T/X/R；不要同时改树深和学习器后称为单因素实验。

固定的数据版本、分割、字段归属、样本对齐、标准化范围、初始化映射和随机序列在可比路线间成对使用。树/LR 的训练轮数不能简单当作相同计算预算；分别设定候选次数和总算力上限，记录实际消耗。需要重新调参的消融，另与固定参数消融区分。

## 5. 数据与统计协议（待执行步骤冻结）

### 5.1 开发和确认

1. 已查看的旧 test 只保留为历史结果，不用于候选排序、调参、翻转分数或确定新特征。开发限定原 train/validation；内部交叉验证/校准均从 train/validation 预分配。
2. 合成数据先验证已知线性、非线性互补、无互补、选择性缺失等机制；明确标注人为生成条件。VertiBench 的启示是特征切分本身需要控制，不能只挑有利切分。
3. 独立确认须来自来源和用途明确、没有看过结果的人群；旧数据重新洗牌不构成独立确认。当前尚未证明存在这样的确认集。若没有，只报告开发证据，不能称“确认有效”。
4. 拟增加其他数据集时先做适用性登记。Home Credit/Santander 可验证高维表格方法，但目标不是营销因果增量；FedAds 可作为广告场景自然分方扩展，许可与字段时点另审；任何两个无身份联系的数据集不得拼成跨企业共同客户。

### 5.2 随机性、区间和多重比较

- 至少五组训练随机种子，可沿用候选 `[11,22,33,44,55]`；**分别记录** split/init/batch-order/特征划分/缺失/重采样种子及其是否实际使用。当前 UCI source_order 不受 split seed 控制，不能伪装五个随机人群。
- 方法间在同 seed、同评价记录上配对。报告每 seed 原值/差值及配对置信区间，另外汇总训练随机性；五训练 seed 不是五个独立数据集。对确定性树重复同配置无额外样本信息，也不得伪称五次独立验证。
- 提议采用 95% 区间、2,000 次有效配对 bootstrap；这是**待冻结参数，不是已完成次数**。Hillstrom 保持随机臂结构，共用同一组重采样记录比较全部模型；同客户多记录按客户成簇。UCI 只有行键，独立同分布假设及源顺序相关性需说明；顺序块重采样作预设敏感性，不声称真实客户簇已知。
- 样本抽样与训练随机性分层描述，不把 seed×同一记录的预测当独立样本。重采样覆盖率/有效重复数不足时输出“不可估”，不临时改区间算法让其通过。
- 预先冻结每任务主指标、对照和多重检验家族；如两邮件臂、多个入围方法，用 Holm 等预声明校正。最终 test 只评估已冻结入围集合，不继续加方案。
- 项目现行严格验收要求仍保留：跨 ≥5 seed、区间不重叠才计项目认可增益；同时补报更合适的配对差值区间和校正 p 值。两种标准若判断不同，分别说明；不得私自以配对区间替代项目门槛。用“显著”必须给出检验、p 值和多重比较口径。
- DR-MX-001 的业务 MDE 暂为相对 20%，由 M6 复核，**不是 AUC/Qini 必须涨 20%**。Qini 或增量基线近零/负值时，相对百分比不稳定；需在执行前把业务目标转换为绝对效应阈值和样本量/功效方案，本步骤不擅自重定。未知成本时只给敏感性分析，不能编造净利润。

## 6. 指标和判决

| 层次 | 指标 | 正确解释 |
|---|---|---|
| UCI 预测 | 提议主指标 AUROC；次要 AP（注明实现，勿与梯形 PR-AUC 混称）、Recall@10%、Precision@10%、Lift@10% | 当前只证明响应预测与名单回测价值，不是营销因果收益 |
| Hillstrom 排序 | 两邮件臂分别 Qini、AUUC、Uplift@10%，相同归一化与随机基线 | 高响应 AUC 不保证高增量排序；不合并/择优隐藏邮件臂 |
| Hillstrom 策略 | 提议主判据为固定 10% 触达预算下相对强本地策略/安全 L1 策略的价值差；另报相对不触达、随机触达 | 用已核实分配概率的 IPW，交叉拟合 DR 作预设敏感性；比较同一测试人群的**配对价值差**，绝对策略价值为正不足以证明联邦增益 |
| 概率质量 | LogLoss、Brier、校准曲线、固定分箱 ECE | 区分排序改善与概率更准；稀有小组的 ECE 不单独作成功条件 |
| 稳定性 | seed 差异、不同验证窗口/预设字段划分、子群效用/校准、最差子群表现 | 不挑最好 seed；代理群体差异不等于通过银行公平性审查 |
| 工程 | 冷/热启动耗时、训练/推理分段耗时、双向总字节/轮次、峰值内存、失败/超时率 | 包括调参、预热、对齐和隐私评估成本；PSI 未运行应单列未测 |
| 数值 | CPU/MPC 偏差、概率范围有效性、边界触发、收敛轨迹 | 真实逐样本量和参数只在获授权方；公开日志不收集秘密值 |
| 安全 | 数据流违规次数、标签推断 AUROC/平衡准确率、成员推断 AUROC/固定低 FPR 下 TPR、属性推断相对先验的误差 | 攻击者只能获得协议允许视图，不能为了跑攻击先发给 Bob 原本不可见梯度；攻击失败不是安全证明 |

为避免库间 Qini 定义不同，执行协议需明确：在处理臂 t 与控制臂的比较人群内，按预测增量排序；以前缀内逆概率加权的结果差构造增益曲线，按该比较人群总数归一化；Qini 面积相对随机排序连线，AUUC 为原增益曲线面积。固定积分、并列分数处理和分母，报告本实现公式与标准库交叉核验。三动作策略在完整目标人群上估计，不混用二臂条件分配概率。

Top-k 排名并列需预先约定固定无标签 tie seed 或边界分数分摊权重，所有方法一致。旧 Top-k 指标/区间保持冻结；若新定义改进，另列版本，不回写历史结果。

**判决依次进行**：数据/数值/披露门禁通过 → 配对统计证据与项目严格门槛 → 业务效应量 → 成本与可用性。失败分别记为数值不合格、隐私不合格、未支持增益、精度可接受但成本不合格；不得把负结果删掉或自动改实验目标。安全硬门失败立即停止，不用预测收益抵偿。

## 7. 建议执行顺序与预算

本轮不执行。下一轮若启动，建议分开声明与提交：

1. **G00：联合数学正确性和评价协议。** 仅合成数值预检及数据来源/可得性确认，先解决解释前置。
2. **C01：少量本地特征工程 + 公平本地对照。** UCI 优先历史缺失状态/非线性，Hillstrom 优先历史金额与近期性；以验证集逐族淘汰。
3. **C02/C03：交互与负迁移。** 分两个步骤，先少量语义交互，再考虑分组收缩；同容量与无信息负对照保留。
4. **C06：Hillstrom 增量学习器；C05：安全树。** 分开实施，避免把因果目标与模型族变化混为一谈。C04 的收敛调优可在各自预算内独立消融。
5. **C07–C12 按具体瓶颈选择。** 没有稳定互补模型不急做 stacking；没有在线依赖问题不急做蒸馏；不为凑“创新点”同时开启全部路线。
6. **独立确认与安全输出验证分步完成。** 冻结入围方案、对照、主指标、MDE/成本上限后才解锁独立确认人群。没有新确认数据则停在开发结论。

预算按“实际拟合模型数”而非 notebook 数计：数据集×四格×训练 seed×候选超参×内层折数，再加因果多模型、折外教师/校准及最终重训。举例：单数据集、四格、五 seed、一个固定配置就有 20 次拟合；这只是预算算式，不是本轮执行记录。旧模型仅在输入/源码/参数/选择规则完全匹配且未越过测试使用边界时只读复用。每轮预先登记最多候选数、墙钟/内存/通信上限与停止规则，不做无限网格。
