## 适用边界

- 补训的 9 棵每棵约 187 秒，比 S5.G2 前 141 棵均值（152 秒）慢 23%，未超过 DR-M5-011 · D-1 的作废线（1.5 倍）；同一台机器当日整体更慢。
- 拟合墙钟口径同 DR-M5-010 · D-3：首段准备加每棵训练耗时；各段重做准备与回放共 1,321 秒，单列不计入。
- 两臂运行方式不同，耗时比只作同机相对量级；通信量按本机回环发送字节计（两方合计，含控制消息）。
- SS-XGB 两次训练结果不完全相同（DR-M5-010 · D-4），只拟合一次，区间未含这部分波动。
- 本步只测精度与成本；SS-XGB 训练中分裂由哪方持有、持有方的分裂阈值仍可见，这部分披露未评估。
- 逐行打分、检查点与日志只在会话临时目录或维护者本机私有目录，不入仓库。
- 技术侧自评，未经法务复核（W-001）。
