# S9.E1 外部隐语 SGB 优化与攻防记录导入

> 编写日期：2026-10-21 ｜ 版本：v1.0 ｜ 状态：执行前声明
> 数据来源：团队仓库 federated_learning_new 之上的扩展实验（云端容器，2026-10-19 → 10-21）的代码、汇总指标 JSON 与说明文档
> 口径基准：所有者要求把扩展实验同步到本仓库；DR-GOV-012（§2.7）；科研实验暂停状态不变

will_produce：在 `docs/04-experiment-records/external/secretflow_sgb_innovations/` 新建外部实验记录：扩展代码（src/ext）、运行队列脚本、汇总指标 JSON（已删除逐特征明细）、创新点说明（原理 / 实现路径 / 结果 / 局限）、散点图与适用边界说明；更新实验记录导航、M9 台账、模块状态与交接记录。

will_not_produce：不在本仓库训练或运行任何实验、PSI、攻击；不启动 VM；不修改任何 `modules/*/results`、冻结配置或既有结论；不提交原始 / 清洗行数据、逐行预测与标签、模型导出、预处理学习参数、IEEE-CIS 交集行数、xlsx；不把单 seed 结果写成本仓库结论。

success_criteria：新 Agent 能从实验记录导航找到该外部记录，并能对每个创新点查到原理、对应脚本与参数、结果 JSON；公开审查逐文件通过（无行数据、交集规模、细分小群体统计、学习参数、凭证）；术语符合 glossary；完整工程门禁通过；以分支推送并开 PR，不改仓库可见性。

risk：结果为单 seed（42），只带测试集 bootstrap CI，不满足本仓库 ≥5 seed 的结论门槛，必须在入口处标明「仅作外部参考」；代码依赖团队私有仓库，独立复现需要该仓库与公开数据集本地副本。
