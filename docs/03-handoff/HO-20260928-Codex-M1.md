## 验收与局限

- 本机实际运行默认拒绝的 macOS 沙箱。读取对方输入/产物、写入对方产物、读取全量源、写入本方输入、通过符号链接访问对方、联网均要求操作系统明确拒绝。文件缺失与端口拒绝连接不视为隔离成功。
- UCI/Hillstrom 各从原件重跑两次；最终验收见本机 `8-9月/实验日志/实验索引.md`。两轮私有数据哈希一致，原件未变，Notebook 从头执行无错误。
- 可移植测试通过模拟执行器验证数据与日志逻辑，不作为内核隔离证据。真实内核测试仅在 macOS 执行，Linux CI 跳过该一项。
- 本轮记录两轮整改：收紧沙箱与修复运行时父目录元数据访问；发现源文件哈希会使标签修改间接改变划分，改成数据集名与序号的模拟键并验证标签翻转不改变划分。中途失败和旧策略运行全部保留，最终验收索引明确排除它们。
- 全仓门禁通过：164 项测试通过，核心逻辑覆盖 1813/1887（96.1%）；47 项门禁回归全部通过。完整日志仅保存在本机验收目录 gates.log；不以测试数替代隐私安全证明。

系统沙箱不是物理隔离。离线分发者与宿主管理员可信，真实企业接入必须在各自环境本地摄入。未完成真实 PSI、安全训练、跨主机身份认证、协议级泄漏评估，训练保持 `blocked`。本步没有模型效果或业务结论。

## 执行方式

安装 `requirements.txt` 或本地 preparation_environment.lock 对应依赖。在仓库工作目录中，以本地 Python 环境调用 `components/execute_preparation.py` 的 `execute`，目标为 `notebooks/S1.P2_isolated_simulation.ipynb`；管理员启动器建立新实验目录并自动启动私有 Notebook。私有 Notebook 需要启动器注入的 CONFIG_PATH，不能独立绕过隔离运行。该入口仅支持 macOS；其它平台应增加并验收对应的隔离后端，禁止无沙箱回退。
