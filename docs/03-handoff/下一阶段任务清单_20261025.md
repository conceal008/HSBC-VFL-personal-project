## 一、阶段目标

到 2027-03 课题结束前达到「决策就绪」，四件事都有证据：

1. **形态判决（S0.9）**：选形态 A、B 还是 C，或者不做联邦。
2. **核心问题一**：L3 相对 L1（本地模型 + 对方 k-匿名聚合统计）有没有增量，在什么条件下有。「没有」也是合格结论。
3. **可验证性**：真实场景下的测试集正例数能否达到 S0.1P 的下界。
4. **盈亏平衡**：盈亏平衡点的坐标，以及业务方是否确认现实可达（项目终点判据）。

## 三、关键路径与顺序

```
T1 ──▶ T4 ──▶ [T5 所有者授权] ──▶ T6 / T7 / T8 / T9 ──▶ T12、T13
 └──▶ T2 ─────────────────────────────────────────────▶ T13
T3（10/30 面聊）──▶ 需求方答复 ──▶ T12、T2 参数更新
```

- **现在就能做**：T1、T2、T3、T4。它们不训练、不运行隐私集合求交（PSI）或攻击、不读封存确认集。
- **等所有者**：T5 是唯一的授权节点。授权前，T6–T11 只能写声明。
- **等需求方**：是否为关键信息基础设施运营者、共同客户数与过去 12 个月首购人数、内地侧签约主体注册地。前两项决定 T12 与 T2 的关键参数。
  S6.P2 显示**应先问共同客户数与可联系人数**：年联系不足 2 万人时其余问题都不改变决策；5 万人以上时是否为关键信息基础设施运营者才进入前列。
