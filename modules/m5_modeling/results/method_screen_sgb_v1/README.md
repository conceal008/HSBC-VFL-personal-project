## 结论

**代理与 SGB 是否一致**（同配置；判据：差的绝对值 ≤ 0.005）

- 13 组比较里 9 组在容差内。超出的 4 组都是 SGB 比代理**高** 0.006 左右：UCI 与 Orange 偏好的原版参数（约 10 桶），以及 mock 重合 80 与 COIL2000 的优化版。
- 按 DR-M5-012 · D-1，这 4 个任务的代理结论降级：UCI 与 Orange 偏好的「原版 → 优化版」幅度以 SGB 为准；mock 重合 80 与 COIL2000 上只有 SGB 实测过的对比可作结论，其余标为「待 SGB 确认」。
- M1、M1x、M6 在 SGB 上与代理的差都在 0.003 以内。

**SGB 上的方法增益**（单次拟合；区间只含测试集抽样）

| 对比 | 任务 | SGB 配对差 [95% 区间] | S5.M1 代理（6 seed） |
|---|---|---|---|
| I2 + I3（优化版 − 原版） | UCI | **+0.010 [+0.001, +0.019]** | +0.018 |
| | Orange 偏好 | **+0.036 [+0.017, +0.057]** | +0.044 |
| M6 bagging − 优化版 | FedAds | **+0.011 [+0.006, +0.017]** | +0.006 |
| | COIL2000 | +0.003 [−0.003, +0.009] | +0.008 |

- I2 + I3 在 SGB 上成立，幅度小于代理（SGB 上原版参数本身比代理高）。
- M6 与 M1x 在 FedAds 的 SGB 上成立；COIL2000 上 M6 区间含 0。
- M1 不显著，与代理一致；UCI 上联邦部分只训 2 棵、拟合 9 秒（优化版 34 棵、169 秒），精度不低于优化版。
