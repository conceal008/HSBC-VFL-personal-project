# 数据处理与 Notebook 运行准则

> 编写日期：2026-09-27 ｜ 版本：v1.0 ｜ 状态：执行中
> 数据来源：本次用户要求、项目仓库 AGENTS.md 与维护约束第 2、9.1 节
> 口径基准：共同客户联合营销；本准则落实用户指定的本地数据管理方式

## 运行入口

后续数据清洗、字段构造、切分和实验均提供 `.ipynb` 入口。Notebook 按步骤解释输入、参数、处理、校验和结果；可复用逻辑位于仓库 `components/`，参数位于 `configs/`。完整运行后的 Notebook 必须保留输出，能够 Restart & Run All。

## 目录必须分开

| 内容 | 位置 |
|---|---|
| 原始下载包与已解压原件，只读输入 | `8-9月/数据集/` |
| 代码、Notebook 源文件、配置、测试、结构说明 | `HSBC-VFL-personal-project/modules/m1_data_selection/` |
| 新产生的数据，包括清洗表、切分表、各方特征、标签 | `8-9月/数据处理产物/<数据集>/<run_id>/` |
| 带输出的 Notebook、报告、校验、运行日志、指纹和结构快照 | `8-9月/数据处理运行结果/<数据集>/<run_id>/` |
| 依赖环境与 Notebook 内核 | `8-9月/数据处理环境/` |

原始数据、新数据、代码和运行结果不可混放。公开仓库只提交代码、配置、测试和允许公开的说明；真实公开数据派生的 Notebook 输出保存在本地，提交的源文件清除输出。数据目录不迁入 Git，也不使用 Git LFS。

## 原始数据保护与追溯

1. 不对原始文件写入、覆盖、改名、删除或原地清洗；读入后产生的任何变化均写入新文件。
2. 每次运行使用新 `run_id`，已有运行目录不得覆盖。失败也保留状态与错误，重跑建立新目录。
3. 开始和结束核对本次读取原件的 SHA-256；源哈希、配置哈希、代码哈希、Git 版本、依赖、时间及种子写入运行指纹。
4. 目录检查按解析后的真实路径进行，拒绝输出到原始目录、仓库内部或互相重叠的目录；不通过符号链接绕过检查。
5. 运行目录保存配置和代码快照、产物清单与校验和，使输出能追溯到对应版本。只有全部校验通过才写完成标志。

## 数据与联邦切分

先明确预测时点和标签，剔除未来信息；先划分训练、验证、测试，再仅用训练集拟合填补、编码和缩放。测试划分冻结，不用于选参。

两方模拟在同一数据集内进行，主动方 Alice 持有标签，被动方 Bob 不持有标签。生成的记录键不作为特征，不能冒充真实客户标识。记录键的重叠测试只是构造的输入条件，未执行密码学协议时不得称已完成隐私集合求交（Private Set Intersection，PSI）。

字段切分、重叠率、漂移和匹配噪声均必须写明构造方法及种子。处理验证不等于模型效果实验；后续效果结论另按至少 5 个种子、置信区间和冻结测试集要求执行。

## 本轮范围

先建立可复用框架并运行 UCI Bank Marketing 与 Hillstrom 的数据准备。输出供后续隐语训练读取；不把目录分离视为安全隔离，不把本地预处理视为联邦训练。其余数据集逐个增加适配器和数据卡，不能用通用 `read_csv` 后直接宣称接入完成。
