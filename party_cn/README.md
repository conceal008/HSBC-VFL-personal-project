# party_cn · 内地侧

《项目维护约束 v2》1.2：`party_cn/` 与 `party_hk/` 两侧分离，**强制体现「互不可读对方数据」**。

## 硬约束

1. **禁止单个配置文件同时包含两侧的端点、凭证或数据路径。** 违反即视为破坏隔离前提，工作作废。
2. 本目录下的组件只能访问内地侧数据与配置；需要对方信息时，只能通过 `platform/` 编排层按 `registry/cross_border_assets.yaml` 已登记的资产交换。
3. 任何跨方通信必须有组件声明（`declaration.yaml`）与审计钩子，否则 CI 门禁 4 阻断。
4. 端点、机构内部命名一律使用占位符，真实值只进本机 `.env`（已 gitignore）。

当前为空，等待 M4 之后的组件落地。
