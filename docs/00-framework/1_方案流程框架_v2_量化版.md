# 跨境共同客户联邦营销：方案流程框架 v2（量化版）

**业务命题**：在内地与香港两个法人主体间，针对双方共同客户，联合建模以提升产品营销转化，全程满足两地法规约束，并具备生产环境可运行的鲁棒性。

**相对 v1 的变化**：全部放行判据量化，取消"完整""明确""充分"这类无法判定的表述；每个模块新增步数预算与关键量化门槛。

**配套文件**：《模块 Loop 执行规范 v2》定义每步怎么做；《项目维护约束 v2》定义怎么协作与留痕。

---

## 零、三个前提判断（不变）

### 判断一：本场景中「交集」是业务目标，不是技术副产品

旧场景（NTB 新客识别）里交集是技术必要步骤，交集小是要克服的问题。本场景中**共同客户 = 交集本身就是营销目标人群**，交集外样本业务上不是目标。

两个后果：
- 「非对齐样本利用」定位改变：从"扩大训练集提 AUC"变为"用本地非对齐样本做自监督预训练改善编码器表示"。方法仍是 FedHSSL/Semi-VFL 一类，但论证逻辑与评估口径完全不同。
- 重叠率同时决定业务盘子大小。**必须把「重叠率→可触达人群规模→绝对收益」与「重叠率→模型增益」分开报告**。

### 判断二：合规是「可用样本域」的定义者，不是事后审查

营销用途下法律基础远弱于风控/反洗钱。内地不能援引"履行合同所必需"，须取得单独同意（PIPL 第 39 条）；香港直接促销受 PDPO 第 6A 部单独约束。

可用人群 = 可匹配 ∩ 交集 ∩ 内地同意 ∩ 香港同意 ∩ 质量达标。**合规折损率是第一等实验变量**，且与效果耦合——同意口径越宽样本越多效果越好但风险越高，这条权衡曲线本身就是方案的核心价值。

### 判断三：跨境在线联合推理不可行，离线批量打分是生产形态

在线 VFL 推理意味着：双方实时在线、每次请求都是独立跨境处理行为（难以逐次论证）、SLA 被跨境网络与密码学开销支配、故障域完全耦合。

生产形态应为：**离线周期性联合打分 → 输出分数/分层名单 → 交付营销执行系统**。倒推三条：延迟不是核心指标（吞吐、批次一致性、可重跑性才是）；必须有单方不可用降级路径；输出的分数与名单仍是个人信息，其流转需单独论证。

## 二、逐模块定义

### M0 · 业务问题定义与合规边界

**目标**：把业务诉求翻译为可证伪的预测命题，输出跨境对象分级清单与可用样本域定义。这是整个方案的地基。

**核心任务**

1. **命题形式化**（单句，四要素）：
   > 给定观察截止日 T，对同时为内地行与香港行客户、且两侧均已取得营销用途所需同意的自然人，预测其在 [T, T+Δ] 内对产品 P 的转化。

   必须明确：产品 P 类别（决定敏感度）· Δ 长度 · 转化定义（点击/申请/开户/首笔交易，四者难度差一个量级）· **业务最小可行规模**（后续 M3 折损漏斗的判负线）。

2. **跨境对象八类分级**（一类不缺）：

   | 跨境对象 | 是否个人信息 | 允许路径 | 备注 |
   |---|---|---|---|
   | 原始特征值 | 是 | 禁止 | 方案前提 |
   | 标识符哈希 | 是（假名化≠匿名化） | PSI 协议内 | 单独哈希可被字典攻击 |
   | PSI 交集结果 | **是（新产生的个人信息）** | 需论证 | 主张不明文落地 |
   | 中间层嵌入 | 大概率是 | 需扰动+论证 | 可反演 |
   | 梯度/加密梯度 | 需个案判断 | 加密后可争取 | 明文梯度可推标签 |
   | 聚合统计（k-匿名） | 可争取为非个人信息 | 相对宽松 | **L1 基线的基础** |
   | 模型参数 | 一般否 | 相对宽松 | 可能记忆样本 |
   | 打分结果/名单 | 是 | 需单独论证 | 常被忽略 |

3. **三条合规姿态并行推演**：R-A 最严 / R-B 标准合同 / R-C 大湾区简化。每条独立推出：可行域 → 可用样本估计（区间）→ 合规成本档 → 落地周期。

4. **两地法律基础**
   - 内地：PIPL 第 13/24/38/39/55/56 条；出境三路径（安全评估/标准合同/认证）；大湾区简化路径适用条件；营销目的须单独同意 + 履行告知义务；第 24 条自动化决策约束
   - 香港：PDPO 保障资料原则 1/3；**第 6A 部直接促销专章**（告知、选择、提供予他人作直销的书面同意）；跨境条文 s.33 未生效但按 PCPD 指引尽职

5. **反向输出技术约束表**：每条法律要求翻译成一条工程约束。例："同意可撤回" → "系统须支持样本级退出，且须回答撤回后模型如何处理"。

### M1 · 数据资产盘点与数据集选型

**核心结论先行**：不存在同时满足四条件的公开数据集——真实两机构纵向切分 / 跨法域 / 有营销响应标签 / 有随机对照可算增量。因此必须双轨：**真实数据作外部效度锚点 + 合成数据作机制实验台**。

**候选评估**

| 数据集 | 契合点 | 主要缺陷 |
|---|---|---|
| Santander Product Recommendation | 多产品交叉销售、月度面板、产品持有序列，语义最贴近 | 单机构、无跨域、无随机对照 |
| Bank Marketing (UCI) | 直销响应标签，语义完全对口 | 体量太小，仅可流程打通 |
| Criteo Uplift / Hillstrom | **有随机分流，唯二能真算 uplift** | 非金融，特征语义不可迁移 |
| Home Credit / FedAds | 团队已熟悉 | 场景是信贷/广告，非跨境营销 |

**强烈建议纳入至少一个含随机对照的数据集**。营销的正确目标是增量转化，不是响应率——高响应人群可能本来就会买。此项缺位是结构性缺陷。

**四种切分协议全做**：S1 随机列 / S2 语义 / S3 语义+漂移 / S4 语义+漂移+匹配噪声。对四者跑同一基线，观察 VFL 增益随切分真实度的衰减。**S1 与 S4 的增益比值就是「伪 VFL 高估效应」的量化证据**，可独立成文。

**量化放行判据**

| 项 | 门槛 |
|---|---|
| 评估数据集数 | ≥4 |
| 每集评估维度 | 6/6（语义契合·uplift支持·语义切分可行·规模·许可·外推能力） |
| 每集"不能回答"条目 | ≥3 |
| 切分协议实现 | 4/4 |
| 增益衰减数据点 | 4 切分 × ≥5 种子，含 CI |
| **S1/S4 增益比值** | 已计算并报告 |
| uplift 数据来源 | 若含 uplift 目标则 ≥1 个随机对照源 |
| 数据卡字段完整度 | 100%（6 字段） |

### M2 · 合成数据生成与仿真台

**目标**：构建参数可调、**ground truth 可知**的双方数据生成器，使"在什么条件下联邦有价值"成为可实验命题。这是最可能形成独立学术贡献的模块。

**路线选择**：主力用**结构因果生成（SCM）**而非拟合真实分布再采样。理由：必须知道"标签信号有多少比例真实来自香港侧特征"才能判断模型是否学到应学的东西。SDV 类方法只复制统计关系，给不出这个真值，作为保真度对照。

**十一项必备可调参数**

| 参数 | 为什么必须可调 |
|---|---|
| 重叠率 ρ | 遍历 VFL–FTL 光谱 |
| **跨方互补度 λ** | **决定 VFL 是否有价值的根本变量** |
| 特征冗余度 | 高冗余下 VFL 增益必然趋零 |
| 边际漂移强度 | 跨境场景的真实特征 |
| 样本量不对称比 | 决定 PSI 协议选型 |
| 正样本率 | 营销场景通常 <5% |
| **同意率与选择性** | 合规折损；同意者非随机会引入选择偏差 |
| **ID 假匹配/漏匹配率** | 跨境标识不一致的必然结果 |
| 时间漂移 | 生产必需 |
| **异质处理效应结构** | 无此项则无法评估 uplift |
| 标签噪声率 | 假匹配的等价表现 |

**创新位置**：现有合成数据工作几乎都是单方视角。本场景需要**双方联合生成器**——两侧特征、共享潜变量、标签生成路径、标识符层匹配噪声，需在统一生成过程中定义。这是文献空白。

**量化放行判据**

| 项 | 门槛 |
|---|---|
| 参数覆盖 | 11/11 |
| **正确性验收偏差** | **理论增益 vs 实测增益 <5%**，配置数 ≥3 |
| 保真度-边际 | KS 统计量 ≤0.1 |
| 保真度-相关 | 相关矩阵 Frobenius 距离 ≤0.15 |
| 保真度-下游 | 模型排序 Spearman ≥0.8 |
| 标准场景数 | ≥6 |
| 复现性 | 同配置同种子输出哈希一致 |
| 无效改进清单 | ≥1 条 |

**升级条件**：正确性验收偏差 ≥5% 且 2 轮修正无法降低 → **禁止进入 M3**。错误实验台上的所有后续结论均无效，此条不可妥协。

### M3 · 实体对齐与样本空间构造

**硬约束**：跨境标识体系不同（内地手机号/身份证/中文姓名 vs 香港 HKID/护照/境外号码/英文姓名），精确匹配覆盖率必然很低。这不是可以假设掉的细节。

**协议选型三维度**：精确 vs 模糊（标识不一致→需模糊匹配）· 平衡 vs 不平衡（规模差异→不平衡 PSI 通信更优）· **交集是否落地**（主张秘密分享形态，双方各持份额，任何一方不获得明文名单）。

**对齐质量是一等实验变量**：假匹配 = 把 A 的特征贴到 B 的标签上 = **标签噪声**。必须做 0/1/3/5/10% 五档敏感性实验。这条曲线文献里少见，跨境场景不可回避。

**合规折损漏斗**

```
内地客户 N₁      香港客户 N₂
     └────────┬────────┘
        标识可匹配   × r₁
        落入交集     × r₂
        内地单独同意 × r₃
        香港直销同意 × r₄
        质量达标     × r₅
     ═══════════════════
        可用样本 N_eff
```

每层给出区间与来源。**N_eff / min(N₁,N₂) 即合规折损率**，它可能低到令人不适——但这正是必须如实呈现的，因为它直接决定项目值不值得做。

**创新位置**：现有 PSI 研究默认单次执行。生产系统按周期重跑，「第 t 期与第 t+1 期交集之差 = 本期新增共同客户」是真实且未被充分讨论的泄露面。

**量化放行判据**

| 项 | 门槛 |
|---|---|
| 对齐路线实现 | ≥3 条 |
| 每路线测量指标 | 5/5（召回·精确·通信量·耗时·泄露面） |
| 敏感性档位 | 5 档（0/1/3/5/10%） |
| 敏感性结论 | 能回答"假匹配 5% 时是否仍优于本地基线"（是/否+数值） |
| 折损漏斗 | 5/5 层，每层含区间与依据 |
| N_eff | 已给出含区间 |
| 重复求交防护 | 泄露量降低幅度已量化 |
| 与 M0 定性一致性 | 100% |

**升级条件**：N_eff 上界 < M0 确定的业务最小可行规模 → 上报 M0 重审同意口径。

### M4 · 特征工程与跨域特征治理

**三条硬约束**

1. **本地加工**：跨方交换的信息必须在 M0 清单内。注意隐性泄露——分箱边界、特征名、缺失率、IV 排名都可能泄露分布，不能因"不是原始数据"就默认可交换。
2. **时间口径统一（跨境场景尤其危险）**：统一观察点 T / 观察窗 / 表现窗；**双方快照冻结协议**须处理结算日与入账延迟差异（香港侧某笔交易晚入账 2 天，就会造成 T 时点两侧信息不同步）；禁止使用 T 之后才可得的信息，含间接可得的。
3. **敏感度分级**：按行业规范分级，最高敏感级直接排除，中敏感级参与需逐项论证必要性与最小化。

**联邦特征筛选三路线**：F-1 完全独立 / F-2 仅交换入模比特 / F-3 加噪贡献度分档。比较筛选质量损失 × 泄露面 × 通信成本。

### M5 · 建模方案与基线阶梯

> 核心不是"用哪个模型"，而是"和谁比"。

**五级基线阶梯**

| 级别 | 方案 | 合规成本 | 作用 |
|---|---|---|---|
| L0 | 内地单方模型 | ≈0 | 绝对下界 |
| **L1** | 内地模型 + 香港 k-匿名聚合统计跨境 | 低 | **真正的竞争对手** |
| L2 | 内地模型 + 香港粗粒度标记 | 低-中 | 定位信息量来源 |
| L3 | VFL 联合建模 | 高 | 待验证方案 |
| L4 | 集中式模型 | 不可行 | 上界（仅合成数据） |

**L1 的重要性**：绝大多数 VFL 研究只比 L0 与 L3，因而系统性高估 VFL。若 L1 以低一个数量级的合规成本拿到八成收益，VFL 在本场景就不划算。**认真做 L1 并如实报告，是本方案严谨性的最强证据。**

**L3 内部四条路线**：SecureBoost（树，表格数据强基线）· SplitNN（支持表示学习）· 联邦逻辑回归（效果上限低但合规与可解释最优，金融场景可能是实际落地首选，不要因"太简单"跳过）· 自监督预训练+树。

**非对齐样本的正确定位**：交集外样本不是营销目标。若使用，目的是**用本地自监督预训练改善编码器表示质量**，评估口径为"预训练是否提升交集内样本效果"。沿用"扩样本提 AUC"表述属论证错误。

**量化放行判据**

| 项 | 门槛 |
|---|---|
| 基线级数 | 5/5 |
| L3 路线数 | ≥3 |
| 种子数 | ≥5，全阶梯一致 |
| 场景覆盖 | ≥6 |
| **L1 完成时点** | **严格早于任何 L3 实验** |
| L3 vs L1 结论 | 三选一，含 p 值与效应量 |
| 效应量与 MDE 比较 | 已完成 |

### M6 · 效果验证与评估体系

**四层指标（逐层递进，缺层不予验收）**

| 层次 | 指标 | 说明 |
|---|---|---|
| 判别力 | AUC, KS | 诊断用，业务意义弱 |
| 业务排序 | Lift@K, Recall@K | 营销只触达 Top-K |
| **增量** | Uplift, Qini, AUUC | **营销的正确目标** |
| 收益 | ROI（含合规与算力成本） | 最终判据 |

**必须显式声明**：响应率高 ≠ 营销有效。真正目标是"因营销而改变行为"的人群。

**三种划分全做**：D-1 随机（学术惯例，高估真实性能）/ **D-2 时间外推 OOT（金融真实口径）**/ D-3 跨群体。D-1 与 D-2 的差距本身就值得报告。

**决策等价性检验**（推荐作为特色指标）：比较 L1 与 L3 各自 Top-K 名单重合度。若重合度极高，AUC 提升 0.01 在业务上等于零——两套方案推给几乎同一批人。K 取业务真实触达规模，不取学术惯例值。这个检验比任何统计量都更能说服业务方。

**条件价值曲线**：横轴取重叠率 ρ / 互补度 λ / 合规折损率 / 同意率，纵轴取 L3 相对 L1 增益，标出**盈亏平衡点**。这是本项目最核心的分析型产出。

**量化放行判据**

| 项 | 门槛 |
|---|---|
| 指标层数 | 4/4 |
| 划分方式 | 3/3 |
| 种子数 | ≥5 |
| CI 覆盖 | 100% 主指标 |
| AUC 报告位数 | ≤3 位小数 |
| D-1 vs D-2 差距 | 已量化 |
| Top-K 重合度 | 已给出数值 |
| 条件价值曲线 | ≥4 横轴变量 × ≥5 点 |
| 盈亏平衡点 | 已给坐标 + 现实可达性判断 |
| 三种聚合一致性 | 已比对 |
| "响应率=增量"表述 | 0 处 |

**升级条件**：L1 与 L3 的 Top-K 重合度 **≥95%** → 上报。VFL 不产生业务差异，即使 AUC 有提升。

### M7 · 安全攻防与隐私评测

**先形式化威胁模型（四维，必须先于防御设计）**：攻击者身份 · 能力 · 目标资产 · 攻击面。**威胁模型不一致是最常见的方案漏洞**——不能一边假设半诚实、一边用只防恶意的机制。

**攻击清单（每条绑定"泄露什么→法律定性→后果等级"）**

| # | 攻击 | 泄露内容 | 法律定性 |
|---|---|---|---|
| 1 | 标签推断（梯度符号/范数） | 香港侧推断内地客户是否购买 | 个人金融信息 |
| 2 | 特征重构（嵌入反演） | 还原对方原始特征 | 原始个人信息 |
| 3 | 成员推断 | "某人同时为两地客户" | 新产生的个人信息 |
| 4 | 属性推断 | 未共享的敏感属性 | 视属性而定 |
| 5 | **PSI 重复求交差分** | 期间新增/流失共同客户 | 生产特有，学术界少讨论 |
| 6 | **分数/名单反推** | 从下发名单反推模型与特征 | 常被完全忽略 |
| 7 | 投毒/后门 | 模型完整性 | 鲁棒性维度 |
| 8 | 贡献伪造/搭便车 | 影响收益分配 | 治理维度 |

第 5、6 条是本场景特有的，**最可能形成差异化贡献**，应投入加倍探索预算。

**创新位置**：现有攻防研究几乎都假设单次训练、单次推理。生产系统按月重跑，**累积泄露**才是真实威胁——一年 12 轮后 ε 还剩多少？不回答这个，DP 就只是装饰。这是学术与工业的真实鸿沟。

## 三、执行顺序与决策点

### 推进顺序

| 阶段 | 模块 | 产出 |
|---|---|---|
| 一 定界 | M0 → M1 | 合规边界 + 数据方案，决定项目形状 |
| 二 搭台 | M2 → M3 | 仿真台 + 对齐方案，可开始实验 |
| 三 建模 | M4 → M5 | **先 L0/L1，后 L3** |
| 四 验证 | M6 ⇄ M7 | 迭代至隐私-效用配置收敛 |
| 五 落地 | M8 → M9 | 工程化与文档化 |

**顺序上最重要的一条**：M5 中先跑 L0 与 L1，再投入 VFL。若 L1 已拿到大部分收益，整个项目结论就会改变，越早知道越好。这也是最容易跳过、代价最大的一步。

### 五个必须先定的决策点

1. **标签方是谁**（内地还是香港发起营销）→ 决定 VFL 架构与主要威胁面
2. **产品 P 是什么类别** → 决定特征敏感度与同意口径
3. **转化如何定义**（点击/申请/开户/首笔交易）→ 四者难度差一个量级
4. **PSI 交集是否明文落地** → 决定合规论证强度与技术复杂度
5. **是否纳入 uplift 评估** → 若纳入，M1 必须补随机对照数据集，M2 必须内置异质处理效应结构

### 三条最可能失败的路径

- **只比 L0 与 L3**：得出"VFL 有显著价值"的高估结论，被问起 L1 无法回答
- **合规折损当附录**：指标漂亮但实际可用样本只有几千人，业务上无意义
- **响应率冒充营销效果**：把本来就会买的人识别得更准，几乎不产生增量收益
