把业务诉求翻译为可证伪的预测命题，输出跨境对象分级清单与可用样本域定义。这是整个方案的地基。

**运行入口**：本模块凡产出处理或实验结果，一律以 `notebooks/<步骤号>_<简述>.ipynb` 为入口并**带输出提交**，使人打开仓库即可直接看到结果（《维护约束 v2》9.1）。逻辑放 `components/`，参数从 `configs/` 读；真实数据派生输出必须清除后再提交。

## 量化放行判据（不达标不放行）

- 预测命题 1 句、四要素齐全、可证伪
- 跨境对象覆盖 8/8 类，每类 ≥1 条法条引用
- 独立推演路线 ≥3 条，每路线 ≥5 个监管质询且回答率 100%
- 主线+回退线各 1 条，回退触发条件可量化
- 约束映射覆盖率 100%；法务独立复核追问 0 次

## 当前结论

**S0.1 已完成（自评 12/12）**，产出 [`problem_statement.md`](problem_statement.md)：

- **命题**：给定 T，对同时为内地行与香港行零售客户、双侧已取得营销用途所需同意、且符合跨境理财通南向通投资者资格的自然人，预测其在 [T, T+90 日] 内**首次成功申购**南向通合资格投资产品的概率。
- **主动方（有标签方）= 内地行**，被动方 = 香港行。
- **业务最小可行规模 N_eff ≥ 30,000 人**（基线转化率 3.0%、待检出相对增益 20%、α=0.05、power=0.80、双臂等分；推导见 [`notebooks/S0.1_mde_sample_size.ipynb`](notebooks/S0.1_mde_sample_size.ipynb)，网格见 [`results/mde_sample_size.csv`](results/mde_sample_size.csv)）。
- **一条必须记住的负面结论**：《Loop 执行规范 v2》0.4 建议的 MDE 初值（相对增益 5%）在本场景要求 N_eff ≥ 41.6 万，不现实。本方案能验证的是**量级为 20% 相对增益**的效果。

⚠️ 四要素与基线转化率**全部为显式假设**，需求方确认前不得作为结论引用（假设清单见 problem_statement.md 第六节）。
