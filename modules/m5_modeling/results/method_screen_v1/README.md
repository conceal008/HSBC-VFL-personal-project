## 结论

| 方法 | 有增益的任务 / 14 | 增益范围 | 明显变差 |
|---|---|---|---|
| 优化版联邦 − 同等调参的内地单边 | 10 | +0.019 ~ +0.072 | 0 |
| 原版参数联邦 − 内地单边 | 7 | +0.014 ~ +0.063 | 2 |
| I2 细分桶 + 同等调参 | 10 | +0.006 ~ +0.049 | 0 |
| I3 先验初始分数 | 2 | +0.003 / +0.026 | 1（名义） |
| I2 + I3 | 11 | +0.005 ~ +0.048 | 0 |
| M6 bagging（6 模型，行采样 0.8） | 7 | +0.004 ~ +0.010 | 0 |
| M1x 逐样本先验 + 非共同客户 | 1 / 4（FedAds） | +0.009 | 0 |
| M1 逐样本先验 | 1 | +0.008 | 5 |
| M4 行采样调参 / M5 匹配置信度 | 0 | — | 0 |

「增益」= 配对差 95% 区间不含 0 且为正（两层 bootstrap：测试客户簇 × 6 个 seed，1,000 次）；Holm 校正后的 p 见 `contrasts.csv`。

## 适用边界

- 代理结论待真实 SGB 复核（DR-M5-012 · D-1：同配置下 AUROC 差的绝对值 > 0.005 则该数据集降级为「待 SGB 确认」）。
- 组合只在验证集上选；单一验证集分不开 0.005 量级的差距，选定组合在 2 个任务上不如优化版。下一轮改为交叉验证选择。
- M5 的错配与置信分数是模拟的（错配 5% / 10%，置信分数区分错配的 AUC = 0.9），结论只适用于这一设定。
- 非共同客户只在 FedAds（官方非对齐训练集抽样）与 mock 重合档（同分布、缺一列）上有。
- mock 编码直接从原始取值做，与 secretflow_sgb_innovations 用的团队母版编码不同，绝对 AUROC 不与 INNOVATIONS 逐位对照。
- 逐行矩阵、分数与原始数据只在会话临时目录或维护者本机私有目录，不入仓库。
